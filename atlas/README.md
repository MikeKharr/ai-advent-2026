# Атлас проекта

Генератор схемы проекта: читает репозиторий по явному списку путей и строит
граф — дни, сервисы, тома, роли, ярусы моделей, классы гейтов, фазы
`/day-cycle`, ADR, записи истории, спецификации дизайна, инварианты, скиллы и
гайды, — плюс рёбра между ними (цитаты, замены, опоры на инварианты,
упоминания ролей, маршруты, зависимости, тома, вызовы внешних сервисов и следы
правил в записях истории).

Решение — `agent_docs/adr/2026-09-13-2000-project-atlas.md`, состав узлов и
рёбер — `agent_docs/design/2026-09-13-2000-project-atlas.md`.

Node 22, без зависимостей.

```sh
node build.js            # пишет dist/graph.json, dist/vault/ и dist/site/ (каталог в .gitignore)
node build.js --serve    # то же плюс статика витрины на http://localhost:8080/
node build.js --check    # только проверка ссылок, ничего не пишет
node --test test/*.test.js
```

`--check` и тесты — шаги обязательной проверки `guard` в
`.github/workflows/docs-guard.yml`. `--check` падает закрыто: цитата
`` ADR `id` `` без файла, путь к `development-history/`, `design/` или
`guides/` без файла, инвариант, которого нет в `agent_docs/invariants.md`,
роль или сервис в `overlay.json`, которых нет в `.claude/agents/` и
`deploy/compose.yml`, внешний узел без единого ребра, строка `compose.yml` вне
подмножества парсера, нечитаемый вход. Сообщение называет файл и строку —
чинится в источнике, не в атласе.

Цитатой не считается и гейтом не проверяется то, что документ показывает как
образец: содержимое блока кода, текст в двойных обратных кавычках
и заглушки шаблонов (`YYYY-MM-DD-HHMM`, `guides/name.md`). Там же, где цитата
написана обычным образом, она проверяется — образец от ссылки отличается
формой записи, а не смыслом.

```text
build.js        точка входа: --check и обычная сборка
lib/sources.js  явный список входов; deploy/*.env, .env*, temp/, logs/, data/ не читаются
lib/markdown.js фронтматтер, разделы, цитаты с номерами строк
lib/compose.js  узкий парсер подмножества compose.yml: непонятую строку возвращает находкой
lib/fired.js    следы правил: имя роли рядом с признаком гейта в записях истории
lib/layout.js   детерминированная силовая раскладка: x, y и z каждого узла
lib/vault.js    заметки Obsidian: фронтматтер, блок происхождения, wikilinks
lib/extract.js  узлы и рёбра, находки для --check
overlay.json    единственный ручной файл: классы гейтов, фазы, внешние сервисы, исключения
```

## Что несёт `graph.json`

Пять вещей страница витрины требует от сборки и не считает сама
(`agent_docs/design/2026-09-13-2100-atlas-page-layout.md`, этап 3):

- **`x`, `y` у каждого узла** — единичный квадрат `0…1`, шесть знаков после
  точки, детерминированная силовая раскладка с фиксированным семенем. Считать
  раскладку в браузере посетителя незачем, а картинка была бы разной от
  запуска к запуску. Стартовый вид «Цикл дня» сюда не входит: он зависит от
  ширины окна и задаётся страницей по номеру фазы.
- **`z` у каждого узла** — глубина для режима «Объём»: `0…1`, шесть знаков,
  поле стоит перед `x`. Считается после `x`, `y` и их не меняет — релаксация
  только по `z` при замороженной плоскости, то же семя; глубина компоненты не
  больше её ширины. Узлы без рёбер — `z = 0.5`. Решение —
  `agent_docs/adr/2026-09-14-1000-atlas-3d-graph.md`.
- **`marks` у ребра `fired`** — `{ unit, role, sign }`, полуинтервалы
  `[start, end)` по `excerpt` до любой обработки разметки. Считаются там же,
  где найден след: второй экземпляр правила в браузере однажды разошёлся бы
  с первым.
- **Выдержка следа без предела длины** — целая фраза или строка таблицы.
  Предел остаётся у выдержек документов в панели.
- **`provenance` в корне файла** — `{ sha, dirty, date }`: полный 40-значный
  hex коммита, признак несохранённых правок в рабочем дереве и дата коммита
  `ДД.ММ.ГГГГ`. Подвал ставит их рядом со ссылками на GitHub, пиная ссылки к
  `sha`: иначе ссылка со старой сборки вела бы на другой текст. Без git полей
  нет — подвал говорит «из ветки `main`».

## Витрина

`web/` — публичная страница `challenge.zpq.ai/atlas/`: `index.html`, `app.js`,
`style.css`. Раскладка — `agent_docs/design/2026-09-13-2100-atlas-page-layout.md`,
токены — `agent_docs/design/corpus.md`. Ноль зависимостей, только браузерные
API; пути относительные, `<base>` нет — страница едет под `handle_path`, как
дни. Сборка кладёт три файла и `graph.json` в `dist/site/`; `--serve` поднимает
на этом каталоге `node:http`, чтобы для локального просмотра не понадобился
`npx serve`.

Ни одно число экрана не написано в разметке: счётчики считаются из
загруженного `graph.json`, потому что граф растёт с каждым документом. Чистая
часть `app.js` — согласование форм слова, сегменты чтения выдержки, подсветка
совпавшего фрагмента, разбор адреса и окрестности — проверяется на собранном
графе в `test/web.test.js`, без браузера.

## Vault

`dist/vault/` — производная копия для Obsidian: каталог открывается в
приложении как хранилище. Заметки несут фронтматтер (`type`, `id`, `title`,
`date`, `status`, `day`, `tags`), блок происхождения по формату
`agent_docs/guides/drive-sync.md` (путь, коммит, время коммита, пометка «копия
только для чтения») и `[[wikilinks]]` вместо цитат. Источник в `agent_docs/`
при этом не меняется — на этом стоит всё решение (I-11, I-12).

Сборка идемпотентна: время в блоке происхождения — время коммита, а не
«сейчас», поэтому повторный запуск на неизменном репозитории даёт побайтово
тот же результат. Чистятся только свои каталоги; `.obsidian/` создаёт сам
Obsidian, и сборка его не трогает.

## Доставка

`Dockerfile` и `Caddyfile` пакета — образ `caddy:2-alpine`, который отдаёт
`dist/site/` и отвечает 200 на `/healthz`. Workflow сначала запускает
`node atlas/build.js`, затем собирает образ (в него идёт только `dist/site/`)
и выкатывает единицу `atlas` на `challenge.zpq.ai/atlas/`. Порядок первого
деплоя — `agent_docs/operations.md`.
