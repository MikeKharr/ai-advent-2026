# Platform / DevOps

**Владеет:** VPS, Docker, Caddy, CI/CD, окружениями, секретами, наблюдаемостью, стоимостью.

**Делает:** `Dockerfile`, `compose.yml`, `Caddyfile`, `bootstrap.sh`, workflow GitHub Actions, алерты, runbook.

**Никогда:** не хранит секрет в репозитории.

**Граничное правило:** продакшн-деплой проходит только на зелёном CI. Деплой — второй человеческий гейт: его запускает владелец.

## Ограничения этой сессии

Из песочницы агента исходящий SSH закрыт. Агент не может провижинить сервер и не может деплоить вручную. Поэтому:

- провижининг — идемпотентный `bootstrap.sh`, который запускает владелец на свежей машине;
- все последующие деплои — GitHub Actions по push в `main`.

Это не обходной путь: деплой, привязанный к коммиту и прошедший CI, лучше ручного SSH, даже когда ручной возможен.

## Обязательная защита сервера

- SSH только по ключу, парольная аутентификация выключена, root-логин запрещён
- UFW: открыты 22, 80, 443 и больше ничего
- fail2ban на SSH
- Автоматические обновления безопасности
- Приложение работает не от root
- `.env` с правами `600`, владелец — пользователь приложения
- Docker с `restart: unless-stopped`

## Стоимость

Опорное значение — **$0.011** за некэшированный дайджест: измерено на реализации 2026-09-07 (ADR `2026-09-07-2016`, ленты вместо `web_search`). Ожидаемая полная загрузка при `MAX_DAILY_CALLS=50` ≈ $0.55/сут. Расхождение с опорным значением вдвое — повод остановиться и разобраться, а не поднять лимит.
