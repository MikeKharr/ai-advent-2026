# Сервер MCP: состояние рабочей копии

Единица дня 31: инструменты `git.branch` и `git.changed` над репозиторием
проекта. Протокол — JSON-RPC ревизии `2025-11-25` без SDK, своя копия внутри
`server.mjs` (четвёртая в проекте — цена границы зависимостей, ADR
`2026-09-28-0736`, п. 3). Решение и контракт —
`agent_docs/adr/2026-10-18-1147-days31-35-assistants-week.md`, раздел дня 31.

**Это локальный процесс.** Его запускает Claude Code на ноутбуке по записи
`mcpgit` в корневом `.mcp.json`; транспорт — stdin/stdout. Контейнера, порта,
маршрута в `deploy/caddy/Caddyfile` и строки в `deploy/compose.yml` у единицы
нет, на VPS её нет вовсе. Отсюда и ветка: сервер отвечает о ветке той
машины, где идёт сессия, а не о `main` в проде.

Зависимостей нет: `package.json` у каталога нет вовсе, и умолчание карты в
шаге «Граница runtime-зависимостей» (`ci.yml`) для единицы вне карты —
ноль. Единицей выкатки каталог не становится: `Dockerfile` отсутствует,
а `ci.yml` и `deploy/deploy-units.sh` знают единицы по закрытому списку имён.

## Инструменты

Оба **без аргументов**: `inputSchema` не принимает ни одного свойства, и
`params.arguments` сервер не читает вовсе.

| Инструмент | Что делает |
|---|---|
| `git.branch` | `git rev-parse --abbrev-ref HEAD` → `{branch, detached}` |
| `git.changed` | `git status --porcelain=v1 -z` и `git diff --name-only -z main...HEAD` → `{working, workingTruncated, base, vsBase, vsBaseTruncated, vsBaseError}` |

Имена в сессии — `mcp__mcpgit__git_branch` и `mcp__mcpgit__git_changed`
(точка → подчёркивание, как у `mcp__project__project_search`).

Нет ветки `main` — `vsBase` приходит `null`, причина в `vsBaseError`, а
состояние рабочей копии отдаётся всё равно.

## Чего сервер не может по построению

- **Выполнить что-то, кроме двух зашитых команд.** Аргументы git — литералы
  массивом в `execFile`, оболочки нет, подстановки нет.
- **Выйти из каталога проекта.** Каталог запуска — `CLAUDE_PROJECT_DIR`,
  иначе `cwd` процесса; из запроса путь не берётся никогда.
- **Залить модель выводом.** Не больше 200 имён в списке, не больше 300
  знаков в пути; срез помечен `truncated`.

Платного вызова единица не делает ни одного: ключей у неё нет, сети нет,
I-4 к ней неприменим — расходовать нечего.

## Локальный запуск

```sh
# Обычно запускает Claude Code по .mcp.json; руками — так:
CLAUDE_PROJECT_DIR=$PWD node mcpgit/server.mjs
```

Один объект JSON-RPC на строку в stdin, один ответ на строку в stdout.
В stdout не уходит ничего, кроме протокола.

## Тесты

```sh
node --test test/mcpgit.test.js
```

Тесты живут в корневом `test/`: он целиком идёт шагом «Данные страницы
прогресса» в `docs-guard.yml` на каждом PR. Сервер в них поднимается
настоящим дочерним процессом во временном git-репозитории.
