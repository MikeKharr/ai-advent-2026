# Как устроен день 5

Схемы к приложению `days/day5/`. Решения — ADR `2026-09-08-1825-day5-article-archive.md`
(архив и отбор) и `2026-09-08-1824-explicit-model-choice.md` (выбор модели).
Эксплуатация — `operations.md`.

## Что где живёт

```mermaid
flowchart LR
  U["Браузер<br/>тема, запрос, выбор модели"]
  C["Caddy<br/>challenge.zpq.ai/day5/"]
  D["Контейнер day5<br/>ключей к моделям нет"]
  V[("Том day5_data<br/>store.json<br/>окно 1000 статей")]
  F["8 RSS-лент<br/>США, Европа, Индия, Китай"]
  R["Контейнер router<br/>ключи, учёт, лимиты"]
  A["Anthropic<br/>claude-haiku-4-5"]
  G["Groq<br/>gpt-oss-20b, qwen3.6-27b"]

  U -->|"POST /api/answer"| C --> D
  D <-->|"читает и дописывает"| V
  D -->|"не чаще раза в 15 минут"| F
  D -->|"POST /v1/route<br/>ключ приложения, выбранная модель"| R
  R --> A
  R --> G

  classDef store fill:#eef,stroke:#88a
  classDef ext fill:#efe,stroke:#8a8
  class V store
  class F,A,G ext
```

Ключей к моделям у дня нет: он предъявляет роутеру ключ приложения, а роутер
держит секреты провайдеров, ведёт журнал расхода и суточные лимиты. Поэтому
стрелки к Anthropic и Groq выходят только из роутера.

## Что происходит за один запрос

```mermaid
sequenceDiagram
  autonumber
  participant U as Браузер
  participant D as day5
  participant V as store.json
  participant F as RSS-ленты
  participant R as router
  participant M as Выбранная модель

  U->>D: тема, запрос, модель, число статей
  D->>D: разбор параметров, лимитер (5/мин, 30/час, 50/сутки)

  alt прошло больше 15 минут
    D->>F: восемь лент параллельно
    F-->>D: записи с текстами
    D->>V: чистка, дедупликация, пополнение, вытеснение — одна запись файла
  else архив свежий
    D->>V: только чтение
  end

  V-->>D: все статьи окна
  D->>D: отбор под запрос, потолок на источник, бюджет 120K символов
  D->>R: POST /v1/route — класс news_answer, провайдер выбран явно
  R->>R: возможность, класс данных, здоровье, суточный лимит приложения
  R->>M: запрос в диалекте провайдера
  M-->>R: ответ
  R-->>D: текст, провайдер, токены, остаток лимита
  D->>D: вырезание ссылок не из подборки
  D-->>U: ответ, модель, токены, сколько статей совпало по запросу
```

Фолбэка на другую модель нет: пользователь выбрал модель, и ответ обязан
прийти от неё либо не прийти вовсе.

## Как отбираются статьи

```mermaid
flowchart TB
  Q["Тема и запрос"] --> T["Слова длиннее двух букв, без стоп-слов"]
  T --> S["Основа слова: «индии» → «инди»"]
  S --> SC["Оценка каждой статьи окна:<br/>заголовок ×3, тело ×1 с потолком,<br/>издание и регион ×2,<br/>плюс добавка за свежесть"]
  SC --> R{"Есть совпадения?"}
  R -->|"да"| K["Лучшие по оценке"]
  R -->|"нет"| N["Самые свежие<br/>поведение дня 3"]
  K --> CAP["Потолок на источник, сквозной"]
  N --> CAP
  CAP --> BUD["Бюджет 120K символов:<br/>дальше только заголовки"]
  BUD --> OUT["Подборка уходит в модель"]

  style N fill:#ffe,stroke:#aa8
```

Совпадение засчитывается только с начала слова, поэтому «акци» не находится
в «реакции». Однокоренные слова основа всё же связывает — «банки» найдут
«банкротство»: это названная цена префиксного сравнения.

## Как устроено окно архива

```mermaid
flowchart LR
  IN["Новые записи из лент"] --> DUP{"Уже есть?"}
  DUP -->|"та же ссылка"| SKIP["Пропустить"]
  DUP -->|"тот же заголовок<br/>за последние 3 суток"| SKIP
  DUP -->|"нет"| ADD["Добавить"]
  ADD --> CAP{"Записей больше 1000?"}
  CAP -->|"нет"| OK["Оставить как есть"]
  CAP -->|"да"| EV["Вытеснить самые старые<br/>у изданий сверх квоты 125"]
  EV --> OK
  OK --> AGE["Отдельно: чистка старше 180 суток<br/>и статей изданий вне списка лент"]
```

Квота нужна потому, что TechCrunch даёт десятки статей в сутки, а Pandaily —
единицы: без квоты плодовитые издания вытеснили бы регионы. Срок хранения и
удаление вместе с лентой делают исполнимым обещание в футере страницы —
издание может попросить убрать свою ленту.

## Границы, которые видно на схемах

- Первый запрос после паузы ждёт загрузки восьми лент: обновление синхронное,
  фоновой таймер отклонён сознательно.
- Русский запрос по английским текстам держится на основе слова и на
  метаданных издания и региона; при нуле совпадений отбор вырождается
  в самые свежие, а число совпавших статей показано пользователю.
- Архив — чужие тексты на нашем диске. Их объём ограничен окном, возрастом
  и списком лент, но приложение остаётся их хранителем.
