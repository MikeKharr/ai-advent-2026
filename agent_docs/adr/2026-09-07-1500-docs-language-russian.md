## Контекст

Шаблон `2030ai/2030ai-project-template` целиком написан на русском. Документы основного проекта владельца (HBK.SG) написаны на английском. Репозиторий `ai-advent-2026` публичный.

## Решение

Проектная документация — на русском, как в шаблоне. Код, имена файлов, slug атомарных документов, названия веток и сообщения коммитов — латиницей.

## Обоснование

Верность шаблону сохраняет чистый diff против upstream: улучшения из `2030ai-project-template` и `cmit-starter` можно подтягивать, не переводя каждый раз. Владелец — носитель языка, и точность формулировок правил для него важнее охвата аудитории: правила читает агент и владелец, а не внешний рецензент.

Смешение языков в именах файлов недопустимо — кириллица в путях ломает часть инструментов и усложняет поиск.

## Последствия

Положительные:

- обновления upstream мержатся без ручного перевода;
- формулировки правил точны для того, кто ими пользуется.

Отрицательные:

- документацию не прочитает нерусскоязычный рецензент челленджа;
- расходится с англоязычной документацией HBK.SG, поэтому при переносе практик потребуется перевод;
- `README.md` публичного репозитория на русском сужает аудиторию проекта.
