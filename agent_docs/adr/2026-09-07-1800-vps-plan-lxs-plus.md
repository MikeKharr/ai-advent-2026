# [2026-09-07 18:00] Тариф VPS-LXS+ вместо Cloud Server XS

## Статус

Заменяет `agent_docs/adr/2026-09-07-1700-vps-readyidc-bangkok.md`

## Контекст

Предыдущее ADR выбрало провайдера ReadyIDC и способ оплаты — переводом. Эта часть решения не меняется и остаётся в силе.

Меняется тариф. ADR `1700` называл **Cloud Server XS** (1 vCPU, 2 ГБ, 30 ГБ, ฿160.50 с НДС). При оформлении заказа выяснилось, что у ReadyIDC две разные линейки, и в линейке **VPS Business SSD** есть тариф с вдвое большими ресурсами за небольшую доплату.

Отдельно: владелец едва не купил **VPS-WXS+** — тот же тариф, но из **Windows**-линейки. Продукты различаются одной буквой в коде (`W` против `L`), а цена Windows-варианта выше на ฿100 и **не включает лицензию Windows**. Весь стек проекта — Docker, Caddy, `bootstrap.sh` на `apt`/`ufw`/`systemd` — работает только на Linux, а Docker на Windows Server запускает Windows-контейнеры; Linux-контейнеры потребовали бы вложенной виртуализации. Ошибка поймана до оплаты.

## Решение

**ReadyIDC VPS-LXS+**, линейка VPS Business SSD (Linux):

| | Было (ADR 1700) | Стало |
|---|---|---|
| Тариф | Cloud Server XS | VPS-LXS+ |
| CPU | 1 vCPU | **2 ядра** |
| RAM | 2 ГБ | **4 ГБ** |
| Диск | 30 ГБ SSD | **100 ГБ SSD** |
| Цена | ฿150 + НДС = ฿160.50 | ฿250 + НДС = **฿267.50** |
| Бэкап | не заявлен | **ежедневный образ, хранение 7 дней** |

Оплачен цикл до марта 2027 года.

## Обоснование

Доплата ฿107 в месяц закрывает недостаток, прямо зафиксированный в ADR `2026-09-07-1610`: при схеме «контейнер на день» память упиралась примерно к десятому дню. 4 ГБ отодвигают потолок за пределы челленджа, и вопрос перестаёт существовать вместо того, чтобы всплыть в середине декабря.

Второе ядро полезно потому, что Caddy и контейнеры дней конкурируют за CPU во время выкатки: сборки на сервере нет, но `docker compose pull` и перезапуск на одном ядре заметно медленнее.

Ежедневный образ с хранением 7 дней — откат всей машины, а не только тега контейнера. Для сервера, куда выкатываются изменения ежедневно, это существенно.

Длинный оплаченный цикл снимает риск, названный в ADR `1700`: ручное продление с загрузкой слипа. До марта 2027 продлевать нечего, а челлендж закончится раньше.

## Последствия

Положительные:

- потолок «контейнер на день» снят на весь срок челленджа;
- откат всей машины из ежедневного образа;
- риск забытого продления снят до марта 2027;
- запас по диску позволяет держать старые образы, не вычищая их агрессивно.

Отрицательные:

- ฿267.50 против ฿160.50 — дороже на 66%, хотя в абсолюте разница мала;
- ресурсы куплены на вырост под неизвестные будущие задания; если челлендж окажется коротким, часть денег потрачена зря;
- оплачен длинный цикл вперёд, поэтому смена провайдера теперь стоит уже потраченных денег.

## Не проверено

- **Тип виртуализации.** Значок Proxmox найден на странице Cloud Server, а куплен продукт из линейки VPS Business — платформа может быть другой. Если это LXC-контейнер, а не KVM, Docker работать не будет. Проверяется командой `systemd-detect-virt` на самой машине.
- **Версия Ubuntu.** ReadyIDC указывает «Ubuntu» без версии. `bootstrap.sh` определяет кодовое имя релиза сам и отработает на 22.04 и 24.04.

Обе проверки выполняются до запуска `bootstrap.sh`.

## Альтернативы рассмотрены

- **Cloud Server XS, ฿160.50.** Дешевле, характеристик хватило бы на первые несколько дней. Отклонён: потолок памяти всплыл бы в середине челленджа, когда переезжать дороже всего.
- **VPS-WXS+, ฿350.** Тот же тариф из Windows-линейки. Несовместим со стеком и дороже; лицензия Windows в цену не входит.
- **VPS-L1SS, ฿500.** 3 ядра, 8 ГБ, 200 ГБ. Избыточно для челленджа.
