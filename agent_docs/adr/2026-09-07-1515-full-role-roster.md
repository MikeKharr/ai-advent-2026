# [2026-09-07 15:15] Полный роестр из 10 ролей агентов

## Статус

Принято

## Контекст

У владельца есть роестр из 10 ролей, разработанный для платформы HBK.SG (`HBK-GOV-002`). Проект `ai-advent-2026` меньше на порядок: около 450 строк кода, без базы данных, без аутентификации, без регуляторного периметра.

## Решение

Перенести все 10 ролей: `architect`, `product-analyst`, `backend`, `frontend`, `data`, `compliance`, `qa`, `platform`, `reviewer`, `docs`. Определить их как Claude Code subagents в `.claude/agents/*.md`, адаптировав границы под масштаб этого проекта.

Сохранить два человеческих гейта: принятие ADR и продакшн-деплой.

Сохранить безусловно: **автор кода не ревьюит свой код**.

## Обоснование

Цель проекта — не только пройти челлендж, но отработать полный цикл, который затем переносится в HBK.SG. Полный роестр здесь — тренажёр: дешевле обнаружить, что роль `data` на проекте без базы простаивает, на маленьком проекте, чем на большом.

Роли с малым объёмом работы (`data`, `product-analyst`) не вредят: субагент, которого не вызвали, не стоит ничего. Вред был бы от отсутствующей роли — прежде всего `compliance`, охраняющей ключ и расход.

## Последствия

Положительные:

- навык переносится в HBK.SG без переучивания;
- `compliance` и `reviewer` присутствуют с первого дня, а не добавляются после инцидента;
- границы ролей записаны в репозиторий и улучшаемы.

Отрицательные:

- часть ролей на этом проекте почти не будет задействована, и их описания рискуют устареть непроверенными;
- десять файлов ролей — заметный объём для проекта в 450 строк;
- есть соблазн вызывать роль ради процесса, а не ради пользы.
