# [2026-09-07 17:00] Хостинг — ReadyIDC (Бангкок), оплата переводом

## Статус

Заменяет `agent_docs/adr/2026-09-07-1535-vps-vultr-singapore.md`

## Контекст

Предыдущее решение выбрало Vultr Singapore, не проверив способ оплаты. Владелец платит **тайской дебетовой картой**, и это ограничение меняет вывод.

Проверено при исследовании:

- Тайские дебетовые карты по умолчанию заблокированы для онлайн-платежей, причём внутренние и международные операции — **разные переключатели** в приложении банка. После волны мошенничества 2021–22 годов банки оставили международные операции строго по заявлению.
- Документация Vultr сама называет две причины отказов, которые бьют ровно по этому случаю: карта не разрешает операции за рубежом (Vultr выставляет счёт в USD) и блокировка эмитентом категорий «recurring / high-risk merchant» — хостинг VPS попадает в эту категорию.
- DigitalOcean прямо отказывает предоплаченным картам и перекладывает 3-D Secure на эмитента. Hetzner не указывает дебетовые карты среди принимаемых и может потребовать паспорт для верификации нового аккаунта.
- **PayPal перестал быть запасным вариантом.** PayPal Thailand требует прохождения NDID с 13-значным тайским удостоверением личности; собственный FAQ говорит, что паспорт, разрешение на работу, розовое удостоверение и вид на жительство не принимаются. Владелец — иностранец, значит этот путь закрыт.

Отдельно выяснилось, что регионы в Таиланде появились у обоих гиперскейлеров — AWS `ap-southeast-7` (январь 2025) и Google Cloud `asia-southeast3` (январь 2026), — но дешёвого инстанса с фиксированной ценой там нет: Lightsail в тайском регионе AWS отсутствует.

## Решение

**ReadyIDC Cloud Server XS**, дата-центр Nonthaburi (Tier 3):

| | |
|---|---|
| Цена | ฿150 + 7% НДС = **฿160.50/мес** |
| Ресурсы | 1 vCPU, **2 ГБ RAM**, 30 ГБ SSD |
| Виртуализация | Proxmox, полный root |
| Оплата | **Банковский перевод / PromptPay** — подтверждено на их собственной форме уведомления об оплате (SCB, KBank) |

Оплата переводом или через PromptPay **не задействует карточные рельсы вообще**, поэтому отказ технически невозможен.

Резервный вариант, если ReadyIDC потребует тайское удостоверение личности: **LightNode Bangkok** ($7.71 ≈ ฿254, 1 vCPU / 2 ГБ / 50 ГБ, свой тайский IPv4), принимает Alipay, Google Pay, UnionPay и большинство карт, тайские документы при регистрации не требуются.

## Обоснование

Главный аргумент — **устранение риска, а не экономия**. Тайский хост с оплатой переводом убирает целый класс отказов: международную блокировку карты, 3-D Secure, категорию высокорискового мерчанта, курсовую разницу. Ни один из них не может сработать, потому что карта не участвует.

Экономия при этом получается сама собой: ฿160.50 против ~฿177 у Vultr — и при этом **2 ГБ памяти вместо 1 ГБ**. Это прямо смягчает недостаток, зафиксированный в ADR `2026-09-07-1610`: при схеме «контейнер на день» память упиралась примерно к десятому дню. С 2 ГБ потолок отодвигается примерно вдвое, то есть за пределы челленджа.

Задержка Бангкок→Бангкок 1–5 мс против ~23 мс до Сингапура. Для этой нагрузки разница несущественна и решающим фактором не была.

Proxmox даёт полноценную виртуализацию, поэтому Docker работает по построению — но **Proxmox умеет и KVM, и LXC**, а контейнеры LXC делают запуск Docker болезненным. Это надо подтвердить до оплаты.

## Последствия

Положительные:

- отказ платежа невозможен: карточные рельсы не задействованы;
- дешевле и вдвое больше памяти, чем в замещаемом решении;
- счета в батах, без курсовой разницы и без 7% НДС поверх долларовой цены;
- сервер в той же стране, что и владелец, — задержка 1–5 мс.

Отрицательные:

- **оператор существенно меньше Vultr.** Ниже вероятность быстрого реагирования на инцидент, панель управления беднее, API скорее всего отсутствует;
- **продление ручное:** оплата счёта и загрузка слипа каждый цикл вместо автосписания. Забытое продление гасит сервер — риск против ежедневного дедлайна;
- **регистрация может потребовать тайское удостоверение личности.** Ни один тайский провайдер не публикует требований к документам; это единственное непроверенное условие, и оно способно заблокировать покупку целиком;
- версия Ubuntu не подтверждена: ReadyIDC указывает «Ubuntu» без версии. `deploy/bootstrap.sh` рассчитан на 24.04, хотя определяет кодовое имя релиза сам и на 22.04 тоже отработает;
- поддержка вероятно на тайском языке;
- расхождение с юрисдикцией основного проекта HBK.SG (Сингапур). Для челленджа несущественно, для переноса практик — нет.

## Проверить до оплаты

Отправить в предпродажную поддержку четыре вопроса. Ответ на третий — блокирующий:

1. Доступна ли Ubuntu 24.04 LTS?
2. Это полноценная KVM-виртуализация или LXC-контейнер? Нужен Docker.
3. Иностранец с тайским банковским счётом, без тайского удостоверения личности — можно ли открыть аккаунт и какие документы нужны?
4. Принимается ли оплата через PromptPay или банковским переводом?

## Альтернативы рассмотрены

- **Vultr Singapore, $5.35 с НДС.** Лучшая панель и инструментарий; Alipay, UnionPay и криптовалюта — документированные обходы карточной проблемы. Но 1 ГБ вместо 2, плюс 7% тайского НДС, и требует включения международных операций в банке.
- **Z.com C1 от GMO, ~฿302.** Единственный тайский хост, у которого Ubuntu 24.04 указана на собственной странице; OpenStack, ISO 27001, крупная компания. Отклонён: способы оплаты нигде не опубликованы, их хелпдеск отвечает 403, консоль ориентирована на тайский язык.
- **LightNode Bangkok, $7.71.** Настоящий дата-центр в Бангкоке, тайские документы не нужны, широкий набор способов оплаты. Оставлен как запасной вариант, а не основной: дороже и оператор менее известен.
- **HostAtom SSD1, ฿310.30.** PromptPay подтверждён, но тип виртуализации нигде не указан — при OpenVZ Docker не заработает.
- **Bangmod Cloud.** Тарифов на 1–2 ГБ нет: скачок с 512 МБ (฿159) сразу на 4 ГБ (฿1 400).
- **AWS `ap-southeast-7`, Google Cloud `asia-southeast3`.** Регионы в Таиланде существуют, но дешёвого инстанса с фиксированной ценой нет; Lightsail в тайском регионе отсутствует.
- **Hetzner.** Дебетовые карты не в списке принимаемых, кошельки и криптовалюта запрещены, возможен запрос паспорта. Практически закрыт.
