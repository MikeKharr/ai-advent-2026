# [2026-09-23 12:27] День 16: сервис MCP на официальном SDK, Streamable HTTP, ключ на входе, инструменты без ключей

Файл: `agent_docs/adr/2026-09-23-1227-day16-mcp-server.md`

## Статус

**Принято** владельцем 2026-09-23. Ранее в тот же день он принял два решения,
которые здесь не обсуждаются: сервер **наш** (пишем и держим службой на VPS),
официальный SDK **разрешён**.

При принятии закрыты развилки:

1. **Ключ эндпоинта — новый `MCP_KEY`** (вариант А). Переиспользование
   `AGENT_KEY` отклонено: утечка через самую молодую службу открывала бы
   службу агентов. Вариант без ключа отклонён — публичный эндпоинт гонял бы
   наш адрес по чужим API от имени анонимов.
2. **Ключ не покидает сервер.** Живёт только в `deploy/mcp.env` и
   `deploy/day16.env` на VPS. Проверка сторонним клиентом (`claude mcp add`
   с ноутбука) из плана **исключена**: она требовала бы вывезти секрет.
   Наблюдаемая проверка — консоль дня 16.
3. **Исключение по зависимостям фиксируется двумя способами сразу**:
   оговоркой в `AGENTS.md` со ссылкой на эту запись **и** стражем в CI.
   Правило без механизма — то, что приходилось чинить весь день 15
   (`guides/verification.md`, «Механизм обязан быть тем, что описан»).
4. **Dependabot** для `/mcp` заводится, но только как уведомление.
5. **Два PR**: служба с конвейером отдельно от дня 16.
6. Форма исключения корпуса по акценту для дня 16 — вопрос фазы раскладки,
   поднимается только если раскладке жёлтый понадобится.

Решения 3–6 приняты оркестратором как рутинные; 1 и 2 — владельцем.

## Решение

1. **Четвёртая единица верхнего уровня — `mcp/`** рядом с `router/`, `agents/`,
   `atlas/`: контейнер `mcp`, порт 8083, Node 22, `@modelcontextprotocol/sdk`
   (1.30.0 на момент ADR). Публичный адрес `https://challenge.zpq.ai/mcp`
   через Caddy адвента, `/mcp/healthz` открыт для выкатки; здоровье контейнера —
   как у `router` и `agents`. Класс изменения — A: `deploy/**`, `.github/**`,
   новый секрет.
2. **Граница исключения из ADR `2026-09-07-1525`.** Runtime-зависимость
   допускается только в единице `mcp/` и только для пакетов протокола:
   `@modelcontextprotocol/sdk` и его обязательный peer `zod`. Версия — точная,
   без `^`; `package-lock.json` в репозитории; в `Dockerfile` —
   `npm ci --ignore-scripts --omit=dev`. Во всех остальных единицах
   `package.json` остаётся без `dependencies`. Держит границу не проза, а шаг
   CI в job `detect` (`ci.yml`): читает каждый `package.json` дерева и краснеет,
   если `dependencies` непустой вне `mcp/` или содержит имя вне списка в
   `mcp/`. Красная ветвь показывается в PR тестом-приманкой. Описание проекта в
   `AGENTS.md` получает одну оговорку со ссылкой сюда, само правило не
   переписывается. Обновления: `dependabot.yml` для npm в `/mcp` раз в
   неделю (уведомление), `npm audit --omit=dev` в job `test` единицы `mcp`
   (блокирующий, но только когда трогают саму единицу). Поднятие версии SDK —
   PR класса A с гейтом `compliance`, по образцу пина инструмента атласа
   (ADR `2026-09-12-0440`, раздел 4).
3. **Транспорт — Streamable HTTP** из SDK, режим без сессий
   (`sessionIdGenerator: undefined`), ответы одним JSON
   (`enableJsonResponse: true`), `GET` и `DELETE` на эндпоинт — 405.
   Транспорт подключается к `node:http` напрямую: `handleRequest(req, res)`
   принимает `IncomingMessage`/`ServerResponse`, Express не нужен. Ревизии
   протокола — те, что негоциирует SDK: `2024-11-05 … 2025-11-25`.
4. **Вход по ключу.** `Authorization: Bearer <MCP_KEY>` на эндпоинте, проверка в
   постоянном времени по образцу `agents/src/service.js` (`bearer`,
   `safeEqual`), 401 до чтения тела. Лимитер на адрес — до исполнения
   `tools/call`, образец `days/day15/limits.js` без суточного денежного
   счётчика: денег у сервиса нет. `MCP_KEY` — новый секрет: `deploy/mcp.env`
   кладёт владелец, копия в `deploy/day16.env` — по норме копии между
   env-файлами (ADR `2026-09-11-1743`, список в `/day-cycle` расширяется этим
   именем). DNS-rebinding-защиту SDK (`allowedHosts`) не включаем: за двумя
   прокси `Host` — то `challenge.zpq.ai`, то `mcp:8083`, а ключ уже закрывает
   то, от чего защищает эта опция.
5. **Инструменты не принимают адресов.** Ни один аргумент не является URL,
   хостом или путём: хосты зашиты в код инструмента, аргументы — строки с
   пределом длины. Исходящий `fetch`: `redirect: 'error'`, таймаут 10 с,
   потолок тела 256 КБ, `User-Agent` с именем проекта. Ответ поставщика —
   недоверенные данные: разбирается, из него берутся названные поля и
   собирается свой JSON; сырой текст наружу не уходит. Сеть compose: `mcp`
   живёт только в новой сети `mcp` вместе с `caddy` и `day16`; в сети
   `default`, где `router`, `agents` и `secrets.env`, его нет — до них не
   разрешается даже имя.
6. **Набор инструментов дня 16 — три, ключей не требует ни один:**
   `clock.now` (без сети — контроль: отличает «MCP не работает» от «интернет
   не работает»), `weather.current` (Open-Meteo: геокодинг по названию города,
   затем текущая температура и ветер), `wiki.summary` (Wikipedia REST
   `page/summary`: заголовок, выдержка, ссылка). Все три видимы глазами: число
   градусов сейчас и текст статьи нельзя подделать заглушкой.
7. **Страница дня 16 — консоль, не чат.** Поле команды, готовые команды
   `initialize`, `tools/list`, `tools/call <имя> <json>`, ответ — сырой
   JSON-RPC как пришёл. Сервер дня (`days/day16/`) говорит с
   `http://mcp:8083/mcp` голым JSON-RPC через `fetch` (заголовки `Accept:
   application/json, text/event-stream`, `Content-Type: application/json`,
   `MCP-Protocol-Version: 2025-11-25`) — без SDK, около ста строк: граница
   п. 2 держится, а посетитель видит протокол, а не обёртку. Лимитер дня — как
   в дне 15. Новый экран — фаза раскладки `design` до кода.
8. **Подключение агента — не в этом ADR.** Два пути названы в «Последствиях»,
   выбор — отдельное решение, когда придёт задание.

## Что проверено лично

- **SDK** (npm-реестр, 2026-09-23): `@modelcontextprotocol/sdk@1.30.0`,
  изменён 2026-09-17, MIT, `engines >=18`; 17 прямых зависимостей, среди них
  `express`, `hono`, `cors`, `jose`, `express-rate-limit` — для нашего пути
  не нужны, но ставятся. Установка `--omit=dev --omit=optional`: **94 пакета,
  26 МБ**, 92 из них без scope (экосистема `jshttp`/`pillarjs`, `ajv`);
  `hasInstallScript` — ни у одного; `npm audit --omit=dev` — 0 уязвимостей.
  Единственная ветка выпусков — `1.x`, `dist-tags.latest = 1.30.0`.
- **Ревизии протокола в SDK** (`dist/esm/types.js`):
  `SUPPORTED_PROTOCOL_VERSIONS = ['2025-11-25','2025-06-18','2025-03-26',
  '2024-11-05','2024-10-07']`. Ревизии **`2026-07-28` в SDK нет**.
- **Поведение транспорта** (`dist/esm/server/webStandardStreamableHttp.js`):
  без `sessionIdGenerator` `validateSession` возвращается сразу
  (`:726-729`) — голый `tools/list` без `initialize` принимается; `Accept`
  обязан содержать оба типа (`:468-470`, иначе 406); `Content-Type` только
  `application/json` (`:475`, иначе 415); `GET`/`DELETE` — 405 (`:442-451`);
  неизвестная `MCP-Protocol-Version` — 400 (`:763-768`).
  `StreamableHTTPServerTransport.handleRequest(req, res)` берёт
  `IncomingMessage`/`ServerResponse` (`streamableHttp.js:124-128`).
- **Спецификация** (modelcontextprotocol.io, ревизия `2026-07-28`, страницы
  `basic/transports/streamable-http`, `server/tools`, `basic/versioning`,
  `basic/security_best_practices`): единственный эндпоинт с POST; `Origin`
  проверять, 403; серверы **MUST** валидировать вход, ограничивать частоту,
  санировать выход инструментов; ревизия `2026-07-28` убрала сессии и
  `initialize`, ввела `_meta` в каждом запросе и `server/discover`; сервер
  только новой эры отвергает старых клиентов, «двуэровый» сервер — MAY.
- **Живые пробы кандидатов** (этот хост, 2026-09-23, `curl`, 12 с):
  Open-Meteo forecast — 200 за 0,9 с, 372 байта; Open-Meteo geocoding — 200,
  0,8 с; Wikipedia summary — 200, 0,4 с, 2,9 КБ; Hacker News `topstories` —
  200, 0,6 с, 4,5 КБ (список id, статьи — по одной, N+1); GitHub API — 200,
  но 60 запросов в час на адрес без ключа; `api.frankfurter.app` — **301**
  (переезд домена — как раз случай для `redirect: 'error'`);
  `worldtimeapi.org` — сброс соединения.
- **Конвейер репозитория:** единица выкатки — каталог с `Dockerfile` по
  образцу `^(days/[^/]+|router|agents|atlas)/Dockerfile$` в
  `.github/scripts/deploy-units.sh` и в `ci.yml` (`detect`); `case` в
  `ci.yml` (`unit`, порты), `context` в `deploy.yml` (`build`) и ожидание
  `healthy` в шаге выкатки перечисляют `router`/`agents`/`atlas` явно —
  единица `mcp` требует правки всех пяти мест. `docker/build-push-action`
  собирает в Actions с сетью — `npm ci` внутри `docker build` там доступен.
- **Сеть из песочницы агента:** `npm view` и `npm install` прошли — причина
  ADR `2026-09-07-1525` («npm возвращает 403») сегодня не воспроизводится.

Неподтверждённым остаётся всё, что собрано по документации поставщика:

- коннектор MCP в Messages API (`platform.claude.com`, бета
  `mcp-client-2025-11-20` / `mcp-client-2026-09-15`): «только tool calls»,
  «сервер должен быть публично доступен по HTTP, Streamable HTTP и SSE»,
  `url` только `https://`, `authorization_token` — Bearer;
- Claude Code: `claude mcp add --transport http <имя> <url> --header
  "Authorization: Bearer …"`, `/mcp` показывает соединение и число
  инструментов;
- **какую эру протокола говорят сегодня коннектор и Claude Code** — нигде не
  сказано; предположение: старую, как SDK;
- условия Open-Meteo (бесплатно для некоммерческого, порядок 10 000
  запросов в сутки) и требование Wikimedia к `User-Agent` — по памяти,
  страницы условий не открывались.

## Обоснование

- Отдельная единица, а не модуль в `agents`: зависимость не должна оказаться
  в контейнере с `ROUTER_APP_KEY`; у `agents` уже 286 тестов и своя машина
  состояний.
- Streamable HTTP — единственный транспорт, который одновременно проходит
  через Caddy, принимается коннектором Anthropic и Claude Code и не
  объявлен устаревшим. Без сессий — потому что сессии убраны в ревизии
  `2026-07-28`, и стороннее состояние на сервере нам не нужно.
- Ключ, а не только лимитер: посетитель без ключа не должен гонять наш VPS по
  чужим API; лимитер защищает от залпа с ключом.
- Хосты в коде, а не аргумент-URL: SSRF закрывается построением, а не
  фильтром адресов; спецификация прямо советует не писать фильтр IP руками.
  Отдельная сеть compose — механизм вместо процедуры
  (`guides/verification.md`, «Переезд переносит и защиту»).
- Граница исключения — шагом CI: «можно SDK для MCP» не должно тихо стать
  «можно зависимости где угодно», а проза границ не держит.
- Гейт ADR `2026-09-08-0205` к npm-дереву не применим буквально:
  SkillSpector сканирует текст скиллов, семантическое ревью 94 пакетов
  невозможно (это уже сказано в `design/2026-09-10-0550-project-atlas.md`,
  строка о гейте). Применим его принцип — проверка на границе установки:
  точный пин, lockfile с `integrity`, `--ignore-scripts`, `audit` в момент
  пина, происхождение SDK — организация `modelcontextprotocol`.

## Последствия

Положительные:

- механизм MCP виден: посетитель посылает JSON-RPC и читает ответ как есть;
- граница зависимостей проверяется машиной, а не памятью;
- агент потом может подключиться коннектором Anthropic через роутер
  (`mcp_servers` + `mcp_toolset`) — без клиентской библиотеки в `agents`.

Отрицательные и цена:

- **Первая цепочка поставки в проде:** 94 пакета, из них нужен один;
  `express`, `hono`, `jose`, `cors` едут в образ мёртвым грузом (+26 МБ к
  образу). Каждое поднятие версии — PR класса A с `compliance`; `npm ci`
  внутри `docker build` делает сборку зависимой от реестра npm — раньше это
  было невозможно по построению.
- **SDK говорит старую эру протокола.** Ревизия `2026-07-28` (без сессий и
  `initialize`, `_meta` в каждом запросе) в 1.30.0 не реализована; клиент
  новой эры получит 400 и должен откатиться сам. Поддержка новой эры в SDK
  придёт, вероятно, мажорной версией — это второй ADR и, возможно, перепись
  клиента дня 16.
- **Клиент дня 16 написан руками** — знание протокола лежит в двух местах
  (SDK-сервер и ручной клиент) и ломается по-разному.
- **`MCP_KEY` — общий секрет без личности клиента:** журнал не отличит день 16
  от Claude Code владельца и от будущего агента. Чтобы владелец проверил
  сервер из Claude Code, ключ должен уехать на его ноутбук — первый секрет
  проекта, которому это положено по замыслу.
- **Исходящий трафик от анонимных посетителей** с адреса VPS к Open-Meteo и
  Wikimedia: их лимиты и баны придутся на наш адрес, тот же, с которого
  ходит роутер. Лимитер отодвигает, не исключает.
- **Лимитер по адресу схлопнется под коннектором:** запросы от Anthropic
  придут с их адресов, все — как один клиент. Решать при подключении агента.
- **Отдельная сеть `mcp`** означает: если агент захочет ходить к серверу
  изнутри compose, а не через публичный адрес, потребуется решение о сети —
  новый ADR.
- **CI единицы `mcp` зависит от сети** (`npm ci`, `npm audit`): красный
  прогон может означать «реестр недоступен» или «вышло advisory», а не
  «версия неверна» — читать по `guides/verification.md`, «Как читать красный
  прогон».
- Локальная разработка впервые требует `npm ci`; в песочнице агента сеть
  сегодня есть, но это наблюдение одного дня.
- Пять мест конвейера (`deploy-units.sh`, `ci.yml` дважды, `deploy.yml`
  дважды) правятся вручную — ошибка в одном молча выкинет единицу из выкатки;
  страж — тест на `deploy-units.sh` с деревом, где есть `mcp/Dockerfile`.

## Альтернативы рассмотрены

- **Протокол руками, без SDK.** Развилка закрыта владельцем 2026-09-23; не
  разбиралась.
- **Транспорт HTTP+SSE (2024-11-05).** Устаревший с `2025-03-26`, к удалению.
- **stdio.** Не проходит через Caddy и недостижим для коннектора.
- **Сервер MCP внутри `agents`.** Зависимость попадает в контейнер с ключом
  роутера.
- **Эндпоинт без ключа, только лимитер.** Любой посетитель гоняет наш VPS по
  чужим API; владельцу оставлена только развилка об источнике ключа.
- **Повторное использование `AGENT_KEY` как `MCP_KEY`.** Копию сделал бы
  агент без нового секрета, но компрометация дня 16 или ноутбука владельца
  открывала бы сервис агентов; вынесено владельцу.
- **Инструмент «fetch любого URL».** SSRF по построению.
- **GitHub API** — 60 запросов в час на адрес; **worldtimeapi** — сброс
  соединения на пробе; **Frankfurter** — 301 на переезд домена, годится как
  запасной после смены адреса; **Hacker News** — N+1 запросов на один вызов,
  запасной.
- **Ревизия `2026-07-28` руками поверх SDK.** Двойная реализация протокола в
  одной единице; ждать SDK.
