# [2026-09-07 15:35] Хостинг — Vultr Singapore, деплой через GitHub Actions

## Статус

Принято

## Контекст

Владелец попросил экономичный VPS. Владелец в Бангкоке, основной проект — сингапурский, поэтому регион Singapore даёт и низкую задержку (~30 мс), и совпадение юрисдикции.

Отдельное ограничение: из песочницы агента исходящий SSH закрыт — проверено, TCP-соединение на порт 22 не устанавливается ни к одному хосту. Агент не может провижинить сервер и не может деплоить вручную.

## Решение

Vultr Singapore, тариф High Frequency: 1 vCPU, 1 ГБ RAM, 25 ГБ NVMe, 2 ТБ трафика, $6/мес. Ubuntu 24.04 LTS. Docker Compose: контейнер приложения и Caddy для автоматического TLS.

Провижининг — одним скриптом `bootstrap.sh`, который владелец запускает на свежей машине. Все последующие деплои — GitHub Actions по push в `main`.

## Обоснование

Vultr в Сингапуре даёт лучшее соотношение цены и производительности среди проверенных вариантов. Hetzner исключён: дешёвые линейки CX и CAX доступны только в ЕС, в Сингапуре есть лишь CPX и CCX, подорожавшие в июне 2026 в 2.4–2.75 раза, плюс наценка за локацию 20–40% — итого около €23–27 за младший тариф. Oracle Cloud Free Tier даёт несравнимо больше машины бесплатно, но ёмкость в регионе часто недоступна, а простаивающие аккаунты отзываются — неприемлемый риск против дедлайна челленджа.

Деплой через Actions — не обходной путь, а лучшая схема: деплой воспроизводим, привязан к коммиту и проходит через зелёный CI. Ручной SSH-деплой агентом был бы хуже, даже если бы был возможен.

## Последствия

Положительные:

- $6/мес, задержка ~30 мс от Бангкока;
- деплой воспроизводим и привязан к коммиту;
- откат — повторный запуск предыдущего workflow.

Отрицательные:

- один инстанс без резервирования, простой при отказе допустим;
- 1 ГБ RAM — потолок, при росте потребуется тариф выше;
- владелец обязан выполнить провижининг сам, агент не может помочь напрямую;
- секрет с приватным SSH-ключом деплоя хранится в GitHub Secrets — новая поверхность риска.

## Альтернативы рассмотрены

- **DigitalOcean SGP1, $6/мес.** Лучшая документация, чуть меньше CPU за те же деньги. Достойная замена, если Vultr не подойдёт.
- **Hetzner Singapore.** ~€23–27 после июньского подорожания и наценки за локацию.
- **Oracle Cloud Free Tier.** Бесплатно и мощно, но ёмкость и отзыв аккаунтов — риск против дедлайна.
- **Cloudflare Workers.** Совпадает со стеком HBK.SG, но владелец прямо попросил VPS.
