# Настройка окружения проекта

Правила настройки рабочего окружения, которые агент должен применить при инициализации проекта.

---

## Когда применять

- При создании нового проекта из шаблона.
- При первом запуске агента в проекте, если конфигурация отсутствует.

---

## Правила

### 0. Сессии запускаются из каталога репозитория

Claude Code и VS Code открываются в корне **этого** репозитория, не в
соседнем проекте. Запуск из чужого каталога стоил трёх утечек автономии
сразу (ADR `2026-09-10-0426`): роли `.claude/agents/` не подхватываются и
эмулируются вручную, хук форматирования применяет чужой конфиг Biome и
портит соседние строки, разрешения `.claude/settings.json` проекта не
действуют. Проверка: в начале сессии роли из реестра
`agent_docs/guides/agent-roles.md` видны как типы субагентов.

### 1. Видимость `.env` в IDE

Цель: `.env` виден пользователю в IDE, но скрыт от git и AI-агентов.

**Создать/обновить `.vscode/settings.json`:**

```json
{
  "explorer.excludeGitIgnore": false,
  "files.exclude": {
    "**/.env": false
  }
}
```

**Проверить/обновить `.cursorignore`:**

```gitignore
# Скрыть секреты от AI-агентов
.env
.env.*

# Но показывать шаблон
!.env.example
```

**Проверить/обновить `.gitignore`:**

```gitignore
# Переменные окружения
.env
.env.*
!.env.example
```

**Проверить/обновить `.env.example`** — шаблон со всеми переменными и пустыми значениями.

### 2. Требования к runtime

- Node 22 или новее. Проверить: `node --version`.
- Runtime-зависимостей нет; `npm install` для работы приложения не требуется.

### 3. Инструменты разработчика (не runtime)

- `skillspector` — сканер безопасности скиллов, обязателен для гейта установки
  скиллов (AGENTS.md, ADR `2026-09-08-0205`). Установка с пином на коммит скилла
  `skill-inspector`:
  `uv tool install 'git+https://github.com/NVIDIA/skillspector.git@704bc95'`
  (uv — `brew install uv`; кладёт бинарь в `~/.local/bin`).
  Использование: `skillspector scan <источник> --no-llm` — LLM-стадию не включать,
  ключ API живёт только на сервере (I-1).

---

## Чек-лист настройки окружения

- [ ] `.vscode/settings.json` создан с настройками видимости
- [ ] `.cursorignore` содержит правила для `.env`
- [ ] `.gitignore` содержит правила для `.env`
- [ ] `.env.example` создан или обновлён как шаблон
- [ ] `node --version` возвращает 22+
- [ ] `skillspector --help` работает (нужен только для установки скиллов)
