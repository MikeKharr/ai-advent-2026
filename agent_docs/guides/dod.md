# Критерии завершенности (DoD)

## Минимальный DoD

- [ ] Результат соответствует требованиям задачи
- [ ] Каждое изменение прослеживается к исходному запросу (нет «попутных улучшений»)
- [ ] Ни один инвариант из `agent_docs/invariants.md` не нарушен
- [ ] `agent_docs/snapshot.md` обновлён
- [ ] Тесты проходят; добавлены новые при необходимости — если применимо к коду (иначе N/A)
- [ ] Документация обновлена; для нетривиальных изменений — отдельная запись в `agent_docs/development-history/`

## Дополнительно по типам задач (если применимо)

### Новая фича / артефакт

- [ ] Обновлена документация пользователя
- [ ] Закрытый пункт перенесён в `backlog-closed.md`

### Изменения UI

Раздел применяется ко всем новым дням. Приложения сданных дней не
поддерживаются и под корпус не приводятся (`agent_docs/design/corpus.md`).

- [ ] `design` участвовал до кода: раскладка, иерархия, четыре состояния контента
- [ ] Ревью `/design-review` пройдено, вердикт `ГОТОВО`
- [ ] Отступы, размеры шрифта и радиусы — только из шкал `agent_docs/design/corpus.md`
- [ ] У каждого интерактивного элемента пять состояний, включая `:focus-visible`
- [ ] Контраст проверен в обеих темах; внешних шрифтов и стилей с CDN нет

### Багфикс

- [ ] Выявлена root cause
- [ ] Добавлен регрессионный тест (если применимо)

### Рефакторинг / реструктуризация

- [ ] Функциональность/смысл не изменены (подтверждено тестами или ревью)
- [ ] ADR создан при значимых изменениях

### Документация / контент

- [ ] Информация актуальна
- [ ] Примеры добавлены (если применимо)
- [ ] Ссылки работают

### Изменения, влияющие на ключ или расход

- [ ] Ревью `compliance` пройдено — у роли право вето
- [ ] Проверено, что лимит проверяется до вызова API, а не после
