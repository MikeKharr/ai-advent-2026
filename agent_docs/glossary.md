# Глоссарий проекта

Специфичные для проекта термины, аббревиатуры, кодовые названия. Помогает агенту правильно интерпретировать задачи и переписку.

## Термины

| Термин | Значение | Контекст |
|--------|----------|----------|
| Сфера (sphere) | Тематическая область, которую вводит пользователь: fintech, climate tech, robotics | Основной вход приложения |
| Дайджест (digest) | Ответ приложения: до трёх новостей по сфере с источниками | `POST /api/digest` |
| Атомарный документ | Один файл на одно событие, имя `YYYY-MM-DD-HHMM-slug.md` | `adr/`, `development-history/` |
| Инвариант | Жёсткое ограничение, нарушение = баг | `agent_docs/invariants.md` |
| Снимок (snapshot) | Состояние работы на текущий момент, ≤300 строк | `agent_docs/snapshot.md` |
| Витрина | Копия решений в Google Drive, только для чтения | `guides/drive-sync.md` |

## Аббревиатуры

| Сокращение | Расшифровка |
|------------|-------------|
| ADR | Architecture Decision Record — запись значимого решения |
| DoD | Definition of Done — критерии завершённости |
| SSE | Server-Sent Events — поток событий от сервера к браузеру |
| TTL | Time To Live — срок жизни записи кэша |
