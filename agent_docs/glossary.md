# Глоссарий проекта

Специфичные для проекта термины, аббревиатуры, кодовые названия. Помогает агенту правильно интерпретировать задачи и переписку.

## Термины

| Термин | Значение | Контекст |
|--------|----------|----------|
| Сфера (sphere) | Тематическая область, которую вводит пользователь: fintech, climate tech, robotics | Основной вход приложения |
| Дайджест (digest) | Ответ приложения: до трёх новостей по сфере с источниками | `POST /api/digest` |
| Атомарный документ | Один файл на одно событие, имя `YYYY-MM-DD-HHMM-slug.md` | `adr/`, `development-history/` |
| Инвариант | Жёсткое ограничение, нарушение = баг | `agent_docs/invariants.md` |
| Класс задачи (task class) | Тип шага для роутера LLM: `rank_news`, `extract_json`, `summarize`, `translate`, `other` — определяет ярусы кандидатов, уровень размышлений и требования к данным | ADR `2026-09-08-1748` |
| Ярус (tier) | Группа провайдеров в политике роутера: `self-hosted`, `cloud-cheap`, `cloud-frontier` | ADR `2026-09-08-1748` |
| Возможность / политика / здоровье | Три механизма выбора провайдера: может ли в принципе, должен ли, может ли сейчас; несоответствие возможности — отказ, не понижение | ADR `2026-09-08-1748`, п. 1 |
| Шов (seam) | Интерфейс, за которым сейчас стоит простая реализация, а позже встанет сложная без переписывания вызывающего кода; пример — реестр провайдеров | ADR `2026-09-08-1748`, п. 2 |
| Отрицательный кэш | Пометка провайдера недоступным на 60 с после транспортной неудачи; на счастливом пути проверок нет | ADR `2026-09-08-1748`, п. 4 |
| Профиль провайдера | Набор умолчаний по доступности, ёмкости и таймаутам: `laptop`, `server`, `cloud` | ADR `2026-09-08-1748` |
| Реестр классов задач | Небольшая явная конфигурация классов; единственный источник уровня размышлений, уходящего в вызов модели | ADR `2026-09-08-1748`, п. 5 |
| Снимок (snapshot) | Состояние работы на текущий момент, ≤300 строк | `agent_docs/snapshot.md` |
| Витрина | Копия решений в Google Drive, только для чтения | `guides/drive-sync.md` |

## Аббревиатуры

| Сокращение | Расшифровка |
|------------|-------------|
| ADR | Architecture Decision Record — запись значимого решения |
| DoD | Definition of Done — критерии завершённости |
| SSE | Server-Sent Events — поток событий от сервера к браузеру |
| TTL | Time To Live — срок жизни записи кэша |
