  панели.
- **Три результата поиска вместо пяти** — по ПРАВКАМ design-review: результат
  с отрывком занимает 104–121 px, а не 76 по расчёту. При пяти результатах
  по «вето» колонке фильтров и списка оставалось 83 px при требовании
  ≥ 200; при трёх — 316–462 px. Остальные найденные видны кольцами на канве и
  в списке.

  с принудительной растеризацией — 27,6 мс по p95 без рычага и 21,4 мс с
  рычагом dpr ≤ 2, при бюджете 16; промежуток между кадрами — 16,7 / 16,8 мс,
  кадры не пропадают. #106 перевёл критерий на работу главного потока по
  трассе, принудительный растр — справочная цифра.
