# [2026-10-05 11:54] Ключ оператора: прогоны проверки идут мимо окон на адрес

## Что сделано

- ADR `2026-10-05-1130` — решение владельца «Ключ оператора», со словами владельца дословно
  и с охватом дней 22–25.
- `EVAL_KEY` в разборе окружения дней 22–25 (`days/day2{2,3,4,5}/env.js`): переменной нет
  или она пуста — возможности нет вовсе, ошибкой конфигурации это не считается.
- `isOperator` и `EVAL_HEADER` в слое лимитов каждого дня (`limits.js`): сверка заголовка
  `x-eval-key` по свёрткам `sha256` через `timingSafeEqual`. Ветвь оператора в `reserve`
  стоит ПОД проверкой суточного потолка и снимает только окна на адрес; отметка адреса при
  этом не ставится (I-10).
- Диспетчеры дней передают признак в слой лимитов и больше ничего о ключе не делают: в
  журнал не пишут ни значение, ни факт присутствия заголовка.
- Прогон дня 22 (`days/day22/eval/run.mjs`) читает ключ из файла (`EVAL_KEY_FILE`,
  умолчание `~/.config/advent/eval.key`), предъявляет его только при создании запуска,
  значения не печатает; без файла идёт как раньше. Пауза с ключом — 6,5 с: её задаёт уже
  окно службы `rag`, а не окно дня.
- Тесты: `days/day2{2,3,4,5}/test/eval-key.test.js` и
  `days/day22/test/eval-key-runner.test.js`. Семнадцать мутаций по номерам строк — в
  описании PR, раздел «Красная ветвь».
- Документация: `EVAL_KEY` в таблицах окружения дней 22–24, раздел в README дня 25,
  раздел про прогон в README дня 22, порядок завода секрета — `deploy/.env.example`.
- Правка ложного утверждения: тест дня 22 назывался «прогон не предъявляет дню никакого
  ключа», а прогон теперь предъявляет один — `EVAL_KEY`. Название и проверка уточнены.

## Зачем

Мера дней 22–25 идёт через публичный адрес одним клиентом, и окна «в минуту/в час» на
адрес считали его обычным посетителем: пауза 13 с между запусками и разбивка набора на
приёмы с перерывом в час. Владелец: «для тестов не надо ждать окно.. ограничения сделаны
для пользователей и программ, чтобы те не слили весь бюджет». Отсюда и граница правки:
снято то, что про частоту; всё, что про деньги — суточный потолок дня и бюджет приложения
$10 — на месте и проверяется первым.
