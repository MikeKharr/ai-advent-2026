# [2026-09-14 18:30] Атлас: ложная ошибка при загрузке и хрупкий тест

Файл: `agent_docs/development-history/2026-09-14-1830-atlas-load-false-error-flaky-test.md`

## Проблема

1. Пока `graph.json` ещё загружался или загрузка падала, `#canvas-msg`
   (`role=status`) на миг показывал «Схему не удалось показать. Cannot read
   properties of null (reading 'nodes')», и только потом — настоящую
   причину. Скринридер мог прочитать ложную ошибку раньше причины. Найдено
   при раскладке сбоя загрузки (`design/2026-09-14-1730-atlas-load-error.md`,
   «Находки», п. 1).
2. PR #80 (только новый документ) падал в `test (atlas)` и `guard` на тесте
   наведения в объёме: тест сидел на живом `graph.json`, а тот растёт с
   каждым документом.

## Что сделано

- **PR #78** (`554b9b0`), класс B. Корень — обработчик `resize`: на
  телефоне событие приходит сразу после загрузки страницы, пока
  `graph.json` в пути. `refresh` отсекал только `status === 'error'`, при
  `loading` читал `state.graph.nodes` при `graph === null`, а его `catch`
  ставил ошибку. Та же дыра — у смены адреса, «Карты», глубины, «Весь граф»
  и сброса фильтров. Правка: `refresh` работает только при `ready`
  (предикат `redraws`, тест `atlas/test/refresh.test.js`). Состояние ошибки
  загрузки не менялось. Стенд с 404, обрывом и битым JSON на пяти ширинах
  320–1600: на `main` ложная ошибка в 15 из 15 прогонов с принудительным
  `resize`, на ветке — 0 из 30. Нормальная загрузка совпала с `main` в
  25 из 25 снимках канвы.
- **PR #82** (`4849828`), класс B, только тестовый код. Упала не проверка
  подписей, а предпосылка `ids.size <= 40`: новый документ связан с
  `compliance`, окрестность выросла с 40 до 41 узла. Кроме того, тест и на
  `main` наведение не проверял: `hover` не доходил до `placeDepthLabels`.
  Заменён двумя тестами на синтетическом виде из 30 узлов: наведение на
  узел с подписью не меняет ни одной позиции; наведённый узел без подписи
  получает имя. Мутации `placeDepthLabels` новые тесты ловят.

## Выкатка

Оба PR смержены 2026-09-11 и выкачены: запуски `deploy` на `554b9b0` и
`4849828` — success. В проде ложной ошибки при загрузке нет.

## Урок

Тест, опирающийся на размер живого графа, ломается от любого документа —
второй случай после «181 узла» в #61. Проверки поведения — на
синтетических видах.
