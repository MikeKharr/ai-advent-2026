# [2026-09-07 21:00] День 1 реализован: дайджест из лент

Файл: `agent_docs/development-history/2026-09-07-2100-day1-implementation.md`

## Что сделано

- ADR `2026-09-07-2016-feed-based-digest.md` принят владельцем; `2026-09-07-1954` помечен
  заменённым.
- Ядро дня 1 по принятому ADR, ноль runtime-зависимостей:
  `rss.js` (разбор RSS и Atom: CDATA, сущности, оба формата дат, дедупликация),
  `feeds.js` (восемь лент, параллельная загрузка, лимит 2 МБ на ленту, таймаут 10 с),
  `digest.js` (фильтр по неделе, отбор кандидатов по кругу источников, сборка карточек),
  `anthropic.js` (выбор моделью по номерам, строгий JSON, санитизация номеров),
  `limits.js` (rate limit на IP и суточный предел, проверка до вызова API),
  `cache.js`, `env.js` (разбор окружения и валидация сферы на границе),
  `server.js` (SSE-прогресс, `POST /api/digest`, `/api/sources`, статика).
- UI: поле сферы, быстрые подсказки, живой прогресс, карточки с датой, изданием, регионом
  и ссылкой на оригинал.
- 20 тестов `node:test`, включая разбор настоящих лент Sifted и TechCrunch, сохранённых
  в `test/fixtures/`.

## Зачем и что проверено вживую

Прогон на сервере в контейнере с настоящим ключом и настоящими лентами:

- восемь лент, 175 свежих материалов за неделю, 120 кандидатов после отбора;
- `fintech`, `climate tech`, `robotics` — по три карточки со ссылками на конкретные статьи,
  датами публикации и пояснениями по-русски;
- цена запроса **$0.011** (вход ~9.5K токенов, выход ~250) против измеренных $0.112 у
  прежней схемы с `web_search` — в десять раз дешевле;
- отклик 13.6 с на холодных лентах, 13 мс при попадании в кэш;
- пустая сфера — 400, SSE отдаёт шаги до результата.

Две правки по итогам живого прогона:

1. Первый прогон дал три карточки подряд из Индии: простая обрезка «первых N по дате»
   отдаёт выборку изданиям, которые публикуют чаще. Добавлен отбор по кругу источников —
   регионы стали разными.
2. Модель отвечала по-английски на англоязычную сферу; требование языка в системном
   промпте усилено.
