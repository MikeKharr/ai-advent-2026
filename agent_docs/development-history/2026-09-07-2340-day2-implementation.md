# [2026-09-07 23:40] День 2 реализован: параметры модели и подсчёт токенов

Файл: `agent_docs/development-history/2026-09-07-2340-day2-implementation.md`

## Что сделано

- `days/day2/` на базе пайплайна дня 1 (ленты, разбор RSS, лимиты, кэш лент — без изменений):
  - `env.js` — `parseParams`: формат (≤500 символов), стоп-последовательности (до 4,
    по одной на строку, ≤100 символов), `max_tokens` (1–2048, по умолчанию 200),
    статей с источника (1–50, по умолчанию 30). Ошибка любого поля — отказ 400,
    а не молчаливый дефолт.
  - `anthropic.js` — свободный ответ без строгой схемы; список кандидатов со ссылками;
    `stripUnknownLinks` вырезает URL не из списка; наружу — `usage`, `stop_reason`,
    `stop_sequence` (ADR `2026-09-07-2330`).
  - `answer.js` — обрезка «не больше N статей с источника» (`capPerSource`), без кэша
    ответов; лимиты проверяются до всякой работы (I-4).
  - `server.js` — `GET /api/answer` (SSE) и `POST /api/answer`; `/healthz` отдаёт `day: 2`.
  - UI: экран из трёх частей — запрос, панель параметров, лента (новые сверху).
    Запись ленты: запрос, дата-время, параметры, токены вход → выход, причина останова,
    ответ. Лента в localStorage (I-10), до 50 записей.
- Деплой: `deploy/Caddyfile` (маршрут `/day2/`), `deploy/compose.yml` (сервис `day2`),
  `deploy/.env.example` (`DAY2_TAG`), ссылка на лендинге.
- 27 тестов `node --test`: 16 новых (границы параметров, доезд параметров до тела запроса,
  белый список ссылок, отсутствие кэша ответов, лимит до вызова API) + 11 разбора RSS от дня 1.

## Зачем и что проверено вживую

Прогон на сервере в контейнере с настоящим ключом и лентами (аналогично дню 1),
три запроса + один сквозной через UI (SSE):

- дефолтные параметры: ответ обрезан ровно на 200 токенах, `stop_reason: max_tokens`;
- свой формат + 600 токенов: формат доехал до промпта, `stop_reason: end_turn`,
  честное «не найдено» по узкой сфере;
- стоп-последовательность `.`: генерация оборвана на первой точке,
  `stop_reason: stop_sequence`, `stop_sequence: "."`;
- UI: прогресс по SSE, запись появилась в ленте сверху с токенами `12528 → 263`
  и параметрами; лента переживает перезагрузку страницы (localStorage).

Расход: вход ~17.8K токенов при 30 статьях с источника (список со ссылками дороже
дня 1 почти вдвое), ~$0.02 за запрос на Haiku 4.5. Проверочные вызовы: 4, ≈$0.07.
Контейнер и файлы проверки с сервера удалены, ключ нигде не фигурирует.
