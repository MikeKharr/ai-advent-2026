## Два факта деплоя, расходившиеся с ожиданиями

1. **Пакет GHCR не пришлось делать публичным вручную:** `advent-day2`, созданный
   workflow в публичном репозитории, оказался доступен анонимно сразу —
   `docker compose pull day2` на сервере прошёл с первого раза. Ручной шаг из
   `guides/new-day.md` не понадобился.
2. **Caddy не подхватил маршрут `/day2/`:** добавление `day2` в `depends_on` сервиса
   `caddy` не заставило `docker compose up -d` пересоздать контейнер (работал 7 часов
   со старым конфигом), и проверка живого адреса в деплое упала. Вылечено
   `docker compose restart caddy` + перезапуск упавшей проверки. Гайд `new-day.md`
   поправлен по факту.
