## Зачем

Решение владельца: приложение дёргает API моделью Haiku 4.5. Прикладного кода ещё нет,
поэтому смена ничего не ломает.

Проверено по документации перед правкой, потому что смена модели тянет за собой форму запроса:

- строгий JSON (`output_config.format`) на Haiku 4.5 поддерживается;
- динамическая фильтрация результатов поиска — только для моделей 4.6 и новее, поэтому
  инструмент переводится с `web_search_20260318` на базовый `web_search_20250305`.
