## Зачем ответы, а не только места

Мера отвечала «нашёл ли поиск нужный документ», и этого хватало для сравнения
стратегий, но не для чтения страницы человеком: место 4 не говорит, **что**
в документе сказано. Ответ с дословной цитатой делает набор вопросов
самопроверяемым: цитату можно сверить с файлом механически, а ответ —
прочитать, не открывая репозиторий.

**q90 — единственная правка предпосылки.** Вопрос спрашивал про «ночную»
задачу, которой нет: расписание `*/15`. Предпосылка убрана. Числа меры не
изменились — q90 вне первой десятки у обеих стратегий и до, и после, то есть
правка не могла подвинуть ни одну метрику.

## Круги ревью #296

- **Блокирующая у обоих гейтов — определение Recall@5 на странице.** Первая
  редакция называла его долей вопросов, у которых верный документ попал в
  пятёрку. `rag/metrics.py` считает иначе: у каждого вопроса берётся доля его
  верных документов, попавших в пятёрку, и доли усредняются. Разница видна
  ровно на тех 7 вопросах, где верных документов два: найденный один из двух
  даёт 0,5. Текст исправлен и объясняет, почему Recall@5 не больше доли
  вопросов с местом не дальше пятого.
- **Переименование по замечанию владельца «что означают цифры?»:** «ранг» →
  «место» во всей странице, «Эталонный документ» → «Верный документ». Слово
  «ранг» ничего не говорило человеку, которому показывают итог.
- Ссылка на источник цитаты не дублируется, когда верный документ у вопроса
  один и совпадает с источником (находка `reviewer`).
