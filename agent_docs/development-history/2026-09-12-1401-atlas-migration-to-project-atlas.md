# [2026-09-12 14:01] Атлас выделен в project-atlas, ai-advent потребляет его клоном по тегу

Файл: `agent_docs/development-history/2026-09-12-1401-atlas-migration-to-project-atlas.md`

## Что сделано

Атлас перестал быть частью этого репозитория. Код инструмента живёт в
публичном `MikeKharr/project-atlas`, ai-advent-2026 получает его в CI клоном
на закреплённом теге и собирает им витрину `challenge.zpq.ai/atlas/`.

Решения: ADR `agent_docs/adr/2026-09-11-1852-project-atlas-extraction.md`
(выделение, PR #125) и ADR
`agent_docs/adr/2026-09-12-0440-atlas-migration-to-project-atlas.md`
(переезд, PR #127, принят владельцем 2026-09-12). Переезд — PR #128,
класс A, гейты `reviewer` + `compliance` + `design-review`.

Что изменилось в этом репозитории:

- `atlas/build.js`, `atlas/lib/`, `atlas/web/`, `atlas/test/`,
  `atlas/package.json` удалены. В `atlas/` остались `Dockerfile`,
  `Caddyfile`, `overlay.json`, `atlas.config.json` (новый, формат 2) и
  переписанный `README.md`.
- `.github/scripts/atlas-tool.sh` — единственное место, где записана версия
  инструмента: `TOOL_TAG=v2.0.1`,
  `TOOL_SHA=27304b80ff7c0aac8ce230373db85558c75f557f`. Скрипт клонирует
  репозиторий, сверяет `HEAD` с `TOOL_SHA` и печатает путь; из клона ничего
  не исполняется до сверки.
- `docs-guard.yml`, `ci.yml`, `deploy.yml` и `deploy-units.sh` зовут
  инструмент через этот скрипт. Шаг «Тесты атласа» ушёл — тесты инструмента
  идут в его CI. Тесты шага секретов вернулись в ai-advent отдельным файлом
  `test/secrets-step.test.js`.
- Формат 2: тип узла `day` стал `unit`, id `day/<key>` → `unit/<key>`, vault
  пишет `units/`, теги `type/unit` и `unit/N`, ключ overlay
  `about.<doc>.days` → `about.<doc>.units`. На витрине семейство «Система»
  подписано «Приложение / Приложения / приложений», подписи рёбер — «про
  приложение» и «документы приложения».

Прод: после мержа #128 выкатка прошла, `/atlas/` и `/atlas/healthz` отдают
200.

## Что проверялось и чем

- **«С точностью до переименования».** На одном дереве собраны две витрины:
  старым пакетом на `merge-base` и инструментом `v2.0.1` на ветке; сравнение
  — командой `node "$ATLAS_TOOL/test/rename-map.js"` по карте раздела 5 ADR:
  `graph.json` после перевода id и типов, `texts.json` байт в байт, vault —
  набор файлов и содержимое каждой заметки после замены каталога, ключа
  фронтматтера и тегов. Координаты `x`, `y`, `z` в карту не входили
  намеренно: их расхождение означало бы смену порядка компонент раскладки, а
  не переименование. Различий нет. Процедура ручная, выполнена один раз в
  A1 и повторена ревьюером по командам из описания PR; в CI она не живёт.
- **Гейт секретов — мутациями.** Тело шага «Секреты не попали в репозиторий»
  вырезается из `docs-guard.yml` и исполняется под `bash -e` во временном
  каталоге: чистый каталог → код 0; файл с образцом ключа (собранным из
  кусков) → код 1, в выводе имя файла и нет тела ключа; нечитаемый файл
  (`chmod 000`) → `grep` возвращает 2 → код 1 с «проверка не выполнилась».
  Без этих мутаций сломанное выражение проходило бы молча.
- **Пин.** Неверный `TOOL_SHA` → скрипт падает с кодом 1 и ни один файл
  инструмента не исполняется; правка файла в существующем клоне → клон
  пересоздаётся (сверяются и `HEAD`, и `git status --porcelain`); верный пин
  → напечатан путь, `HEAD` равен `TOOL_SHA`. `TOOL_SHA` взят
  `git rev-parse v2.0.1^{}` в клоне, а не из описания релиза.

## Чем это оплачено

- **CI зависит от сети на каждом PR.** `guard` обязателен для `main` и
  теперь клонирует чужой репозиторий при каждом прогоне, включая документные
  PR. Три попытки с паузой закрывают короткий сбой; долгий даёт красный
  `guard` сразу у всех открытых PR. Кэша нет намеренно — это ещё одно место,
  где может оказаться не тот код.
- **Сбой клона в выкатке роняет job `build` целиком**, и `deploy`
  пропускается для **всех** единиц запуска, а не только для атласа.
  Прежний контейнер при этом продолжает отдавать `/atlas/`, а отложенные
  единицы подберёт следующая выкатка по базе `detect`.
- **Смена версии инструмента — всегда PR класса A**, даже ради одной подписи:
  путь `.github/**` защищён, а инструмент пишет публичную страницу.
- **Подписи витрины сменились для посетителя**: «Дни» → «Приложения».
  Вернуть слово можно только ключом конфигурации, то есть форматом 3.
