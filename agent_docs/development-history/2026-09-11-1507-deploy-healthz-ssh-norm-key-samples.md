## Зачем

Задачи владельца от 2026-09-11 по пунктам «Владельцу» из #113 и находке F1:
выкатка не должна падать ложным красным, пока Caddy возвращает единицы в
работу; доступ агента к серверу должен держаться списком, а не окном
подтверждения, которого больше нет; ключ в документе должен останавливать
сборку, а не прятаться.
