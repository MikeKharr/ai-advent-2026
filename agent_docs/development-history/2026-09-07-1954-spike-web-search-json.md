## Зачем

Спайк был единственным, что могло заставить переделать архитектуру дня 1. Он же должен был
дать фактические числа расхода вместо оценок и проверить условия приёмки по I-7 и I-9,
записанные до запуска в ADR `2026-09-07-1910`.

Результат:

- связка работает: strict tool use на `publish_digest` дал валидную структуру за один вызов;
- **опровергнут вывод из документации** — `output_config.format` с `web_search` не отклоняется
  (HTTP 200, валидный JSON, цитаты на месте). Неверная формулировка в ADR `2026-09-07-1910`
  (статус «Предложено») исправлена; блок условий приёмки в нём не тронут;
- цена измерена: $0.104 и $0.112 за дайджест против прежней оценки $0.085;
- **выбранный вариант в этом прогоне свою же валидацию не прошёл**: модель проставила всем
  трём карточкам URL раздела издания. Поэтому выбор в ADR предварительный, с гейтом на
  повторном замере перед UI;
- условие приёмки по I-9 не выполнено: у страницы раздела нет даты события;
- отклик 61 с против записанного требования «до 15 с» — требование приведено к факту.
