# [2026-09-07 19:54] Спайк web_search + строгая структура: прогон и результат

Файл: `agent_docs/development-history/2026-09-07-1954-spike-web-search-json.md`

## Что сделано

- Владелец выпустил `ANTHROPIC_API_KEY` и положил его на сервер (`deploy/put-secrets.sh`),
  поставил биллинг-алерт и включил branch protection на `main`. Проверено: файл
  `secrets.env` с правами 600, защита ветки требует PR, `guard` как обязательная проверка,
  force-push запрещён.
- Спайк выполнен на сервере в контейнере `node:22-alpine` с `--env-file secrets.env`:
  ключ не покидал сервер и не появлялся в выводе (I-1).
- Пять вызовов API, около $0.24. Проверены три варианта сборки дайджеста; замеры и выводы —
  в ADR `2026-09-07-1954-web-search-strict-json.md`.

## Главное

- Связка «поиск + строгая структура одним вызовом» **работает**: strict tool use на
  `publish_digest` дал валидную структуру за один вызов.
- **Опровергнут вывод из документации**: `output_config.format` с `web_search` не отклоняется.
  Контрольный вариант вернул HTTP 200 и валидный по схеме JSON с цитатами. Неверная
  формулировка в ADR `2026-09-07-1910` (статус «Предложено») исправлена.
- **Цена измерена**: $0.10–0.11 за дайджест против прежней оценки $0.085. Причина — вход
  55–65K токенов. Прогноз `compliance` подтвердился.
- **Найден дефект качества**: в основном варианте модель проставила всем карточкам URL раздела
  издания вместо ссылок на статьи. Проверка «URL из выдачи поиска» это пропускает — нужны
  дополнительные условия, они записаны в последствия ADR.
- **Доступность ссылок не проверяется HTTP-запросом**: издание отдаёт 403/405 и на HEAD, и на
  GET. Трактовка I-7 требует уточнения.
