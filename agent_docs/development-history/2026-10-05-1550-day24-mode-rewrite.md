# [2026-10-05 15:50] Режим дня 24 — `rewrite`: правило ADR применено числом прогона дня 23, а не правкой сервера

Файл: `agent_docs/development-history/2026-10-05-1550-day24-mode-rewrite.md`

Нового решения здесь нет: применяется принятое правило ADR
`2026-10-05-0544`, п. 2.4 — «`rewrite`, если MRR@10 после отбора выше
`rerank` не меньше чем на 0,02, иначе `rerank`». Числа дала мера дня 23
(PR #327): **0,533** против **0,436**, разница **0,097 ≥ 0,02**. Решение
владельца 2026-10-05 — переключать по ADR, умолчанием в коде, с повтором
прогона 10 вопросов.

## Что сделано

- `DEFAULT_MODE` в `days/day24/env.js` — `rewrite` вместо `rerank`. Режим
  по-прежнему называет **сервер дня**, не посетитель: поле `mode` в теле
  запроса не читается, выбора режима на экране нет.
- Переключение сделано **умолчанием в коде, а не строкой
  `deploy/day24.env`**: режим задан решением ADR, и правка файла на сервере
  руками уводила бы его из-под диффа и из-под гейтов. Переменная `RUN_MODE`
  осталась — ею возвращается дешёвый `rerank` без правки образа.
- На сервере переменной нет: `deploy/day24.env` содержит только `AGENT_KEY`
  (проверено закрытой командой списка имён переменных), то есть умолчание
  кода не перебивается, и руки владельца не нужны.
- Тест умолчания переписан под новую правду
  (`days/day24/test/server.test.js`, «RUN_MODE проверяется по списку, а
  умолчание — режим правила ADR»): умолчание `rewrite`, явный `rerank`
  принимается, чужое значение откатывается в `rewrite` с ошибкой
  конфигурации. Прежний тест на явное значение проверял `rewrite` — после
  смены умолчания он перестал бы различать «явное значение принято» и
  «всегда умолчание», поэтому явным стал `rerank`.
- Текст, называвший режим, приведён к новой правде в четырёх местах:
  `days/day24/README.md` («Режим один, и называет его сервер», «Расход»,
  таблица окружения), `deploy/.env.example` (описание `deploy/day24.env`),
  `agent_docs/guides/day24-cited-contract.md` («Вход»), комментарии
  `days/day24/env.js`. Фразы «числа дня 23 ещё нет» в репозитории не
  осталось (греп по `Числа дня 23`).

## Расход

Счёт — ADR, п. 4: `rewrite` — три вызова модели (переписывание, отбор,
ответ) и два эмбеддинга на запуск, ≈ **$0,013**; `rerank` — два вызова, один
эмбеддинг, ≈ $0,012. Суточный потолок дня `MAX_DAILY_CALLS` 50 **не
меняется**, и верхняя оценка дня остаётся **50 × $0,013 ≈ $0,65** при
потолке **$10 в сутки** приложения `agents` — ровно число, которое ADR уже
посчитал для дня 24. Эмбеддингов стало **100** из 500 суточных службы `rag`
(было «не больше 100» при одном эмбеддинге у `rerank` и двух у `rewrite`);
счётчик общий с днём 22 и Claude Code владельца. Повтор прогона 10 вопросов
в новом режиме — ≈ $0,15, отдельной задачей.
