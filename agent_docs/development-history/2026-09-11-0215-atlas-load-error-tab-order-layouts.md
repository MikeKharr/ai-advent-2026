# [2026-09-11 02:15] Атлас: раскладки сбоя загрузки и порядка Tab

Файл: `agent_docs/development-history/2026-09-11-0215-atlas-load-error-tab-order-layouts.md`

## Проблема

Два пункта `backlog.md` из «Находок» спецификации фокуса после шага
(`design/2026-09-10-1756-atlas-focus-after-step.md`) меняют раскладку,
поэтому по ADR `2026-09-10-0426` раскладка идёт до кода:

1. На узком экране ошибку загрузки не видно и не слышно — текст и
   «Попробовать снова» лежат в скрытом блоке канвы.
2. В двух колонках и на узком экране порядок `Tab` расходится с экраном:
   список узлов в DOM раньше панели.

## Что сделано

- **PR #81** (`de42ba4`), класс C — `design/2026-09-11-0153-atlas-load-error.md`.
  Ошибка загрузки на всех трёх раскладках — в панели: заголовок «Схему не
  удалось загрузить», причина, «Попробовать снова» и «Открыть репозиторий».
  Объявление — одно на исход попытки через `#live`, у `#canvas-msg`
  снимается `role="status"`. Фокус на первый отказ не переносится; после
  успеха — на `#panel-h`. Пока графа нет, «Карта» и масштаб недоступны,
  «Фильтры и вид» и список скрыты, `refresh()` ничего не делает.
- **PR #80** (`fcdec78`), класс C — `design/2026-09-11-0207-atlas-tab-order.md`.
  Один порядок DOM во всех трёх раскладках: колонка графа → поиск → «Карта»
  → «Фильтры и вид» → панель → «Узлы в этом виде» → подвал. `order` в
  `style.css` не остаётся. В трёх колонках список уходит под панель, на
  узком экране фильтры встают выше панели, две колонки на экране не
  меняются. Прототип: последовательность `Tab` совпадает с видимой при
  1600, 1280 и 360.

## Развилки

Владелец спал; обе раскладки идут по рекомендации `design`, вернуться, если
владелец решит иначе.

- Сбой загрузки: место на широком экране — панель, а не канва; «Фильтры и
  вид» и список скрыты, а не недоступны; строка «Попыток: {n}»; фокус на
  первый отказ не переносится.
- Порядок `Tab`: панель перед списком во всех раскладках (цена — путь к
  списку от `#panel-h` через панель, медиана 8 нажатий, максимум 49); на
  узком экране фильтры выше панели (+87 px); подвал последний в обходе.
