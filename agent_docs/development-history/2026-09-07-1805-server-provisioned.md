## Пойманная ошибка

В корзине оказался **VPS-WXS+** — тот же тариф из **Windows**-линейки. Продукты различаются одной буквой кода (`W`/`L`), и на странице заказа это видно только по подписи «VPS Business SSD (Windows)» и по выпадающему списку ОС.

Цена Windows-варианта на ฿100 выше и **не включает лицензию Windows** — предупреждение об этом на странице набрано по-тайски мелким красным шрифтом.

Технически покупка была бы тупиковой: `bootstrap.sh` построен на `apt`, `ufw`, `fail2ban` и `systemd`, а Docker на Windows Server запускает Windows-контейнеры; для Linux-контейнеров нужна WSL2 или Hyper-V, то есть вложенная виртуализация, которую VPS обычно не предоставляет.

Ошибка поймана до оплаты по скриншоту корзины.

## Зачем нужна была замена ADR

ADR `1700` называл конкретный тариф и цену. После покупки другого тарифа документ стал бы просто неверным, а принятые ADR не редактируются. Выбор провайдера и способа оплаты при этом не менялся — заменяющая запись касается только тарифа и явно это оговаривает.

## Осознанно не записано в репозиторий

IP-адрес сервера в документацию не внесён. Репозиторий публичный; адрес всё равно будет виден через DNS, но публиковать его в документации — лишняя подсказка для сканеров. Адрес живёт в GitHub Secrets (`SSH_HOST`) и нигде больше.
