# [2026-10-05 10:13] Потолок цитаты режет, а не отвергает: дословные цитаты m01 и m02 перестали теряться

Файл: `agent_docs/development-history/2026-10-05-1013-quote-cap-truncates.md`

Решение — ADR `2026-10-05-1013-quote-cap-truncates.md` (ответ владельца
дословно там же). Правка — в модуле дня 24, которым пользуется и день 25.

## Что сделано

- `verifyQuotes` (`agents/src/rag/cited.js`) режет цитату длиннее 300 знаков
  до первых 300 знаков **до** сверки; слагаемое `needle.length <=
  MAX_QUOTE_CHARS` из условия `verified` снято. Наружу полем `text` уходит
  обрезанный текст, рядом — новое поле `truncated`.
- Обрезка считает знаки (`Array.from`), а не единицы UTF-16: `slice` рубил бы
  пару surrogate пополам и возвращал тот же ложный отказ.
- Четыре теста в `agents/test/cited-agent.test.js`: дословная цитата в 388
  знаков подтверждается обрезанной; цитата во весь фрагмент наружу целиком не
  выходит; цитата ровно в потолок не обрезается; цитата с эмодзи не рвётся
  пополам. Тест «цитата во весь фрагмент сверку не проходит» заменён: его
  предмет — что фрагментом во весь экран цитата быть не может — остался, а
  прежнее утверждение `verified: false` перестало быть правдой.
- Контракты и README дня 24 больше не обещают отказа за длину.

## Зачем

Прогон дня 22 на `cited-agent` дал по m01 и m02 исход `unsupported` — тот же
признак, которым помечается выдумка. Все цитаты этих ответов дословные;
отвергала их одна длина (388 и 312 знаков). Пока дословная цитата и
выдуманная получают один вердикт, различение дня 24 не работает.

## Проверено

- `node --test test/cited-agent.test.js` в `agents/`: 18 из 18. До правки те
  же четыре теста красные.
- Мутации (по позиции строки, прогон после каждой — красный): обрезка снята —
  падают три теста; знаки заменены единицами UTF-16 — падает тест с эмодзи;
  граница потолка сдвинута (`<=` → `<`) — падает тест о цитате ровно в
  потолок.
- Весь прогон единицы: `npm run test:node22` — 550 из 550 (локально Node 22,
  `node:sqlite` только под флагом). `days/day24`: 167 из 167 — страница
  разбирает `quotes[]` по полю и лишнего не читает.
- Повтор сверки офлайн по артефактам запусков m01/m02 (вызовов API нет): обе
  цитаты m01 (388 знаков) и цитата m02 (312) — `verified: true`,
  `truncated: true`, 300 знаков; исход обоих стал бы `answered` вместо
  `unsupported`.
