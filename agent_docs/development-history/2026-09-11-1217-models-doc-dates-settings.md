## Что сделано

- **#107 (класс C):** docs-PR прошлой итерации — записи истории о главной
  как странице прогресса и об атласе с полным графом и поиском, snapshot,
  backlog, строки журнала #99–#106.
- **#108 (класс B, защищённые пути):** во фронтматтере ролей — полные id
  моделей: `architect` — `claude-fable-5-1`/high, остальные —
  `claude-opus-5[1m]` с прежним усилием. `design` переведён с high на
  medium по решению владельца; это закреплено ADR `2026-09-11-1105`
  (заменяет `2026-09-10-0426` в части яруса `design`). Суффикс `[1m]`
  проверен запуском Claude Code 2.1.267 (`claude -p --model …`):
  `claude-opus-5[1m]` даёт контекст 1M, у `claude-fable-5-1` суффикс
  принимается, но молча отбрасывается, поэтому у Fable его нет. В атласе id
  яруса стал безопасной формой (`tier/claude-opus-5-1m-medium`), подпись —
  без префикса `claude-`. Цена: полный id закрепляет версию модели, на
  новую Opus или Fable роли сами не перейдут.
- **#109 (класс C):** ADR `2026-09-11-1046` о датах в именах атомарных
  документов. Диагноз: у 57 документов от PR #29 имя позже мержа на 8–88 ч —
  имена ставились «после предыдущего», у агента не было часов. Решение
  владельца: переименовать по времени мержа (UTC), новые имена — из
  `date -u`, проверка в CI.
- **#110 (класс B):** 57 файлов (48 идентификаторов) переименованы по времени
  мержа своего PR, UTC; 589 ссылок переписаны, даты в текстах поправлены;
  таблица — `development-history/2026-09-11-1104-rename-future-dated-docs.md`.
- **Инцидент после мержа #110.** Около 11:42Z `/atlas/` и `/day5`–`/day8`
  около минуты отдавали 503. Причина: выкатка пересоздавала семь контейнеров
  (комментарии с идентификаторами ADR поменялись в коде единиц), а Caddy
  возвращает единицу в работу только по active health check с интервалом
  30 с. Шаг «Проверка живого сайта» проверяет `/healthz` без повторов,
  поэтому выкатка упала. Сайт восстановился сам, перезапуск упавшей части
  выкатки — зелёный.
- **#111 (класс B):** `docs-guard` проверяет имена в `adr/`,
  `development-history/`, `design/` скриптом `.github/scripts/doc-names.mjs`:
  формат (теперь и в `design/`), часы и минуты, существующая дата, время не
  позже запуска проверки плюс 10 минут. Пункт 1 роли `docs` — имя из
  `date -u`. Тесты — `test/doc-names.test.js`.
- **#112 (класс B):** из `.claude/settings.json` убран список
  `permissions.ask` целиком (rerun и cancel запусков, force-push) по решению
  владельца: ни одна shell-команда не ждёт клика. Force-push в `main`
  по-прежнему закрыт защитой ветки. Закреплено ADR `2026-09-11-1154`
  (заменяет `2026-09-11-0513` в части списка `ask`).

## Зачем

Задачи владельца от 2026-09-11: видеть в ролях точную модель и контекст;
вернуть датам документов смысл — порядок имён снова совпадает с
хронологией, и CI не даёт поставить дату из будущего; убрать ожидание клика
для shell-команд.
