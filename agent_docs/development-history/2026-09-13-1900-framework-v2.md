# [2026-09-13 19:00] Фреймворк v2: модели по ролям, классы гейтов, day-cycle

## Что сделано

Реализовано принятое владельцем решение ADR `2026-09-13-1800`.

- **Фронтматтер ролей** (`.claude/agents/*.md`): всем двенадцати ролям
  заданы `model` и `effort` по ярусам — fable/high у проектирования и
  гейтов, opus/medium у реализации, opus/low у записи. Шести ролям
  предзагружены skills Османи через `skills:`.
- **Новая роль `design-review`** (fable, high, предзагружен скилл
  `/design-review`): гейт мержа для UI выделен из `design`; `design`
  остался раскладкой до кода, обязательной только для новых экранов и
  смены раскладки.
- **Скилл `/day-cycle`** (`.agents/skills/day-cycle/` + зеркала в
  `.claude`/`.codex`/`.cursor`): исполняемый протокол передачи — десять
  фаз с ролями, гейтами по классу изменения (A/B/C) и критериями выхода.
- **`.claude/settings.json`**: точечный allowlist рутинных команд (тесты,
  линт, `gh`, ssh на сервер выкатки), deny на чтение env-файлов; режим по
  умолчанию не ослаблен.
- **Формат-хук `hbk-template`** ограничен файлами своего проекта: чужой
  Biome-конфиг больше не переписывает файлы этого репозитория (причина
  находки B ревью дня 8).
- **`AGENTS.md`, `agent-roles.md`, `environment-setup.md`** приведены к
  решению: ярусы моделей, классы гейтов, перепроверка тем же экземпляром,
  запуск сессий из каталога репозитория.

## Отступления и принятые остатки

- **Explore → haiku** фронтматтером не реализуем (встроенный агент);
  ярус задаётся параметром `model` при вызове — правило записано в
  `/day-cycle`.
- **Ревью внедрения**: compliance ставил вето (произвольный ssh на прод,
  «конфиг CI» в классе C) — allowlist сужен до трёх форм `docker compose`,
  workflow с `secrets.*` переведены в класс A; поправка отражена в ADR.
  Reviewer дал ПРАВКИ — диаграмма приведена к day-cycle (гейты
  параллельно после qa), гомоглиф в ADR исправлен, фикс формат-хука
  закоммичен в `hbk-template` (5d11e2b).
- **Второй круг вето**: хвостовая `*` внутри кавычек ssh пропускала
  `; cat secrets.env'` — ssh-формы стали точными строками без глоба
  (логи убраны из allowlist); `git diff --stat -p --no-index` печатал
  файл в обход deny — формы `--stat` заякорены, deny переписан срединным
  глобом `*--no-index*`. Compliance показал главное: **мерж кодового PR
  и есть продакшн-деплой** (`deploy.yml` триггерится на push в main),
  поэтому `gh pr merge` переведён в ask — клик совпадает по смыслу с
  человеческим гейтом выкатки; deny — `*--admin*` срединным глобом.
  Снять клик может только явное решение владельца.
- **Принятые остатки** (зафиксированы ревью, правкой не закрывались):
  `node --test *` исполняет произвольный JS репозитория — без этого нет
  автономных тестов; deny на `Read` не останавливает `Bash(cat …)` — это
  свойство механизма разрешений, не конфигурации.
