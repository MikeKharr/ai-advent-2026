## Что из этого не очевидно

1. **«Воспроизводимо» сделано свойством, а не обещанием.** `backlog.close`
   ищет якорь сначала в архиве: якорь там и пункта в очереди нет — `changed:
   false` без единой записи. Отсюда следствие, которое проверяет тест: второй
   прогон того же сценария на том же дереве даёт пустой `git diff`.
2. **Исходный текст пункта переносится в архив не из вежливости.** По нему
   якорь и находится в архиве на втором прогоне — то есть сохранение текста
   есть механика идемпотентности. Мутация «не переносить исходный текст»
   красит именно тест воспроизводимости.
3. **Третье состояние названо отказом, а не повтором.** Якорь в архиве и пункт
   ещё открыт — это след сбоя между двумя записями (двух файлов одной
   операцией не записать). Тихий повторный перенос сделал бы из одного пункта
   два, поэтому здесь отказ с объяснением.
4. **Порядок записи выбран по цене отказа посередине:** сначала архив, потом
   вычерк из очереди. «Пункт в обоих файлах» виден и правится, «пункт нигде» —
   потерянный текст.
5. **Защита пути — в ОДНОМ месте намеренно.** Первая редакция `resolveInRoot`
   проверяла выход за корень дважды: лексически (`..`, абсолютный путь) и
   сверкой `realpath`. Под мутацией это вскрылось сразу: снятие любой из двух
   проверок оставляло прогон зелёным, то есть ни одна не была держателем
   (I-14). Осталась одна сверка `realpath`, она закрывает все три формы — `..`,
   абсолютный путь и симлинк наружу, — и её снятие красит тест.
6. **Проверка пути наружу чуть не оказалась пустой.** Первый вариант теста
   читал `../../etc/hosts`: от временного каталога macOS этот путь не
   существует, отказ приходил по причине «файла нет», и тест не различал
   гипотезы «защита работает» и «пути просто не существует». Теперь путь
   собирается `relative()` до настоящего файла снаружи, и тест проверяет, что
   его содержимое в ответ не попало.
7. **`.env` закрыт по имени уже разрешённого пути.** Ключи на ноутбуке лежат
   в `.env` (I-1, I-3), а новой возможности сервер не даёт: `Read` в сессии и
   так есть. Закрыто ради скилла, у которого в `allowed-tools` только четыре
   инструмента MCP, — там этот сервер единственная дверь к файлам.
