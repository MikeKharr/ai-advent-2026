# [2026-09-10 16:02] Атлас 3D: решение, данные, раскладка режима «Объём»

Файл: `agent_docs/development-history/2026-09-10-1602-atlas-3d-decision-data-layout.md`

## Что сделано

Владелец попросил вращать граф атласа как трёхмерный. Цель — впечатление и
демонстрация, работающее при этом не должно сломаться. За итерацию смержены
три PR из четырёх шагов ADR. Кода страницы ещё нет.

- **ADR** `agent_docs/adr/2026-09-10-1420-atlas-3d-graph.md` — PR #58
  (`4ca1d18`), класс C. Владелец принял его как есть: по всем шести развилкам
  приняты рекомендации архитектора. Плоский вид по умолчанию, режим «Объём»
  включается флажком. В объёме перетаскивание вращает граф, `Shift` с
  перетаскиванием сдвигает. Автоповорота в первом объёме нет. Режим в адрес
  не пишется. Объём на карте телефона — тем же кодом. Работа идёт двумя PR:
  контракт данных, затем страница. ADR атласа `2026-09-10-0550` не правится,
  новый ADR уточняет его п. 3.
- **Контракт `z`** — PR #59 (`1bec065`), класс B, `backend`. Новая
  `depth()` в `atlas/lib/layout.js`: та же силовая модель, что в плоскости,
  но двигается только `z`, а `x`, `y` заморожены. `layout()` не изменена ни
  строкой, поэтому `x`, `y` совпадают байт-в-байт. В узле `z` стоит перед
  `x`, порядок ключей `z, x, y`: так diff `graph.json` с main состоит только
  из добавленных строк `"z"`. Глубина компоненты ограничена её шириной в
  плоскости и центрирована на 0.5. Без этого предела главная компонента
  вытягивалась бы в столб в 1.38 раза. Узлы без рёбер получают `z = 0.5`.
  Фактический диапазон — 0.16…0.84. На проде `z` есть у всех 180 узлов.
  `graph.json` вырос на 3637 байт.
- **Раскладка режима** `agent_docs/design/2026-09-10-1517-atlas-3d-mode.md` —
  PR #60 (`8bc4a41`), класс C. В ней флажок «Объём» с тремя дословными
  пояснениями, проекция и начальная поза, переходы, кодирование глубины
  радиусом, подписи в движении и в покое, управление, `aria-live` и критерии
  приёмки для `design-review` и `qa`. Раскладка атласа
  `2026-09-10-1155-atlas-page-layout.md` не правится.

## Решения владельца

- Центр вращения — центр куба `(0.5, 0.5, 0.5)`, как в ADR. Граф вписывается
  в поле по огибающей 15 поз вокруг текущей и только при смене вида, не в
  каждом кадре вращения.
- На ширине 73–100rem флажок остаётся в свёрнутом блоке.
- В окне карты своего флажка нет.

## Что стоит помнить

**Тест полосы вида падал на «181 узел».** Документ #60 стал 181-м узлом
графа, и CI его PR упал. Регулярка `узл\S+` не принимала форму «узел», а
код витрины был верен. PR #61 (`02ab91b`) сузил регулярку до трёх форм
слова и добавил табличный тест согласования числа и слова. Подробнее —
в `2026-09-10-1603-atlas-visit-trail.md`.

**Трейлеры соавторства в main.** С PR #55 по #61 squash-мержи несли
`Co-authored-by: …@192.168.1.33`: личность git в рабочей копии не была
задана. Починено через `git config` в репозитории и явный текст сообщения
при squash. Начиная с #60 трейлеров нет.
