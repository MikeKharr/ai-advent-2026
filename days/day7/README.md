# День 7 — чат с агентом и память диалога

`https://challenge.zpq.ai/day7/`

День 6 отвечал на одиночный запрос. День 7 — переписка: агент помнит
сказанное раньше, в том числе после собственного перезапуска. История
диалога живёт в SQLite на томе агента, сессия определяется cookie, которую
ставит этот день; срок хранения — 30 часов без новых сообщений.

Решение — `agent_docs/adr/2026-09-12-0930-day7-chat-sessions.md`,
раскладка — `agent_docs/design/2026-09-12-0900-day7-chat-layout.md`.
День 6 остался в проде без изменений.

## Локальный запуск

```sh
AGENT_KEY=<ключ сервиса агентов> \
AGENT_URL=http://127.0.0.1:8082 \
COOKIE_PATH=/ COOKIE_SECURE=false \
node server.js
```

Тесты: `node --test test/*.test.js` (10) — сервер дня против поддельного
сервиса агентов: cookie сессии, лимитер, создание запуска, прокси потока,
чтение и очистка переписки.

## Эндпоинты

| Путь | Что |
|---|---|
| `POST /api/answer` | лимитер → запуск у агента с идентификатором сессии → `202 { runId }` |
| `GET /api/runs/:id/events` | прокси SSE потока событий агента |
| `GET /api/chat` | переписка сессии; `DELETE` — удаляет её и начинает новую |
| `GET /api/state` | описание агента, модели, готовые запросы, состояние архива, срок хранения |
| `GET /healthz` | конфигурация цела |

## Переменные окружения

| Имя | Умолчание | Смысл |
|---|---|---|
| `AGENT_KEY` | — | ключ сервиса агентов, обязателен |
| `AGENT_URL` | `http://agents:8082` | адрес сервиса агентов |
| `AGENT_ID` | `news-analyst` | какой агент отвечает на этой странице |
| `COOKIE_PATH` | `/day7/` | путь cookie: браузер шлёт её только на адреса этого дня |
| `COOKIE_SECURE` | `true` | `false` только для локального запуска по http |
| `SESSION_TTL_HOURS` | 30 | срок жизни cookie, совпадает со сроком хранения у агента |
| `MAX_DAILY_CALLS` | 50 | суточный предел запусков с этого адреса |
| `RATE_LIMIT_PER_MIN` | 5 | окно на адрес: запросов в минуту |
| `RATE_LIMIT_PER_HOUR` | 30 | окно на адрес: запросов в час |

## Сессия

Идентификатор сессии выдаёт сервер в cookie `day7_sid`: `HttpOnly`,
`SameSite=Lax`, `Secure`, `Path=/day7/`. Скрипты страницы его не видят и
в хранилище браузера он не лежит; страница вообще не знает, в какой она
сессии. Значение не по форме UUID не принимается — заводится новая сессия.

`Path` границей безопасности не является: все дни живут на одном домене,
и скрипт соседнего дня может обратиться к `/day7/` сам. Он лишь сужает
адреса, на которые браузер шлёт cookie.

«Очистить» удаляет переписку у агента и начинает новую сессию: старый
идентификатор больше ничего не адресует.

## Чем отличается от дня 6

- Чат вместо ленты: сообщения хранятся на сервере, а не в браузере, и
  переживают перезапуск агента и перезагрузку страницы. Cookie живёт в одном
  браузере, поэтому на другом устройстве будет другая переписка.
- Ответ агента несёт сводку итерации: что сделал, сколько токенов **одним
  числом** (вход плюс выход) и сколько контекста ушло.
- Новый параметр «размер контекста» (0–8000, по умолчанию 3000). Он задаёт
  желаемый хвост диалога; действующий размер меньше, если предел входа
  модели не позволяет, и это видно рядом с полем.
- Параметры переехали в свёрнутый блок над полем сообщения: колонку под них
  занимает диалог.
