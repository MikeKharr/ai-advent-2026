# День 6 — агент как сервис и монитор его работы

`https://challenge.zpq.ai/day6/`

Запрос выполняет отдельный агент (`agents/`, ADR
`agent_docs/adr/2026-09-10-1000-agent-service.md`): держит архив статей,
отбирает подходящие, спрашивает выбранную модель через роутер и проверяет
ссылки. Страница дня — пульт к нему: отправляет запрос, показывает ход
работы в мониторе над лентой ответов и сам ответ. Ссылка «Об агенте»
открывает окно передачи: имя, версия, назначение и системный промпт с
кнопкой копирования. Раскладка — `agent_docs/design/2026-09-10-day6-monitor-layout.md`.

У дня нет ключа роутера и своих данных: только ключ сервиса агентов.

## Локальный запуск

```sh
AGENT_KEY=<ключ сервиса агентов> \
AGENT_URL=http://127.0.0.1:8082 \
node server.js
```

Тесты: `node --test test/*.test.js` (9) — сервер дня против поддельного
сервиса агентов: лимитер, создание запуска, прокси потока, возврат слота.

## Эндпоинты

| Путь | Что |
|---|---|
| `POST /api/answer` | лимитер → `POST /v1/runs` у агента → `202 { runId }` |
| `GET /api/runs/:id/events` | прокси SSE потока событий агента |
| `GET /api/state` | описание агента, модели, готовые запросы, состояние архива |
| `GET /healthz` | конфигурация цела |

## Переменные окружения

| Имя | Умолчание | Смысл |
|---|---|---|
| `AGENT_KEY` | — | ключ сервиса агентов, обязателен |
| `AGENT_URL` | `http://agents:8082` | адрес сервиса агентов |
| `AGENT_ID` | `news-analyst` | какой агент отвечает на этой странице |
| `MAX_DAILY_CALLS` | 50 | суточный предел запусков с этого адреса |
| `RATE_LIMIT_PER_MIN` | 5 | окно на адрес: запросов в минуту |
| `RATE_LIMIT_PER_HOUR` | 30 | окно на адрес: запросов в час |

## Чем отличается от дня 5

- Логика запроса живёт у агента, а не на странице: день не собирает промпт,
  не ходит в роутер и не держит архив.
- Монитор агента над «Ответами»: события запуска новыми сверху, группировка
  по запуску, до пяти запусков в памяти страницы, без сохранения.
- Окно передачи с системным промптом агента — с сервера, а не из страницы.
- Отказ агента до траты денег (пустой архив, предел модели, отказ роутера
  без вызова провайдера) возвращает слот суточного лимита дня.
