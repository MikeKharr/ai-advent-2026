# День 18 — планировщик

Экран ленты сводок планировщика: состав работы, ближайший срок, стартов сегодня из потолка,
остаток бюджета и лента сводок с раскрываемым трейсом. Идущий запуск приходит по SSE.

Решение — ADR `2026-09-28-0736`, пп. 6, 7, 9.

## Что делает единица

Только показывает. Запуски заводит планировщик внутри сервиса агентов; ручки «запустить» у дня
нет ни под каким методом, и это проверяется тестом. Включают и выключают работу правкой
`agents/config/jobs.json` через PR, не с экрана.

## Ручки

| Ручка | Что делает |
| --- | --- |
| `GET /healthz` | состояние настройки и статистика лимитера |
| `GET /api/digest` | сводка планировщика от сервиса агентов, тело **как есть** |
| `GET /api/runs/:id/events` | поток событий запуска, насквозь |

## Неутверждённый контракт

`GET /v1/jobs/digest` в сервисе агентов и имена полей сводки **не утверждены**: ADR п. 7
называет данные, но не ручку. Все догадки собраны в двух местах и больше нигде:

- путь — `JOBS_PATH` в `server.js`;
- имена полей — `shapeDigest` и `shapeRun` в `public/digest.js`.

Когда ручка появится, правятся эти два места.

## Окружение

`AGENT_KEY` (обязателен, копия по закрытому списку), `AGENT_URL` (умолчание
`http://agents:8082`), `AGENT_ID`, `RATE_LIMIT_PER_MIN` 5, `RATE_LIMIT_PER_HOUR` 30, `PORT` 8080.
Денег единица не тратит: суточного счётчика у неё нет.

## Раскладка

Своей раскладки у дня нет. `public/style.css` — дословный срез блока `<style>` дня 16;
совпадение держит `test/style-copy.test.js`. Собственных токенов, цветов и шкал страница
не заводит.

## Запуск локально

```sh
AGENT_KEY=dev AGENT_URL=http://127.0.0.1:8082 node server.js
node --test
```
