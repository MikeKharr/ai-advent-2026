# День 2 — параметры обработки запроса к модели и подсчёт токенов

**URL:** `https://challenge.zpq.ai/day2`
**Порт в контейнере:** 8080
**Образ:** `ghcr.io/mikekharr/advent-day2`

## Состояние

Работает. Поверх пайплайна дня 1 (восемь RSS-лент, фильтр по неделе) пользователь управляет
параметрами обработки запроса и видит расход токенов. Экран из трёх частей: запрос,
панель параметров, лента результатов (новые сверху).

Параметры:

| Поле | Куда уходит | По умолчанию |
|---|---|---|
| Формат ответа | в промпт, свободным текстом | краткий дайджест по пунктам |
| Статей с источника | обрезка кандидатов перед моделью | 30 (1–50) |
| Условие завершения ответа | `stop_sequences` (до 4, по одной на строку) | нет |
| Останов по токенам | `max_tokens` | 200 (1–2048) |

Запись ленты: запрос, дата-время, параметры, токены (вход → выход), причина останова
(`stop_reason` / `stop_sequence`), сам ответ. Лента хранится в localStorage браузера —
сервер запросы пользователей не хранит.

В отличие от дня 1 ответ — свободный текст, поэтому строгая JSON-схема не применяется,
а ссылки модель берёт из выданного ей списка; ссылка не из списка вырезается из ответа
(`stripUnknownLinks`). Ответы не кэшируются: смысл дня — видеть эффект параметров.

## Устройство

| Файл | Что делает |
|---|---|
| `rss.js` | разбор RSS и Atom без зависимостей: CDATA, сущности, дедупликация |
| `feeds.js` | список лент, параллельная загрузка, лимит 2 МБ и таймаут на ленту |
| `answer.js` | фильтр по неделе, обрезка N статей с источника, сборка записи ленты |
| `anthropic.js` | вызов Messages API со `stop_sequences`/`max_tokens`, вырезание чужих ссылок |
| `limits.js` | окно на IP и суточный предел, проверка до всякой работы |
| `cache.js` | кэш лент (ответы модели не кэшируются), одна работа на ключ |
| `env.js` | разбор окружения, валидация сферы и параметров на границе |
| `server.js` | SSE-прогресс, `/api/answer`, `/api/sources`, статика |

## API

- `GET /api/answer?sphere=fintech&format=…&stop=…&max_tokens=200&per_source=30` —
  SSE: события `progress`, затем `result` или `error`.
- `POST /api/answer {"sphere":"fintech","format":"…","stop":"…","maxTokens":200,"perSource":30}` —
  один JSON-ответ.
- `GET /api/sources` — список лент.
- `GET /healthz` — 200, либо 503 при неполной конфигурации.

## Важно про префикс

Как в дне 1: Caddy срезает `/day2` через `handle_path`, все ссылки и `fetch` — относительные,
`<base>` не нужен и вреден (подробно — `days/day1/README.md`).

## Переменные окружения

Общие для всех дней, из `deploy/secrets.env`. `MAX_OUTPUT_TOKENS` здесь — потолок
для пользовательского `max_tokens` (по умолчанию 2048).
